# HAT-022 터치 피아노

## 인스턴스 선언

HAT-022 터치 피아노(HAT022) 블록을 작업 영역에 추가하면, Python 코드에는 다음과 같은 인스턴스 선언이 자동으로 삽입됩니다:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### 매개변수

| 이름 | 구분 | 설명 | 범위 / 종류 | 기본값 |
| --- | --- | --- | --- | --- |
| index | 드롭다운 옵션 | 인스턴스 번호 (0부터 시작) | 0 이상 정수 | 0 |

<br>

## 터치 피아노 시작하기 {#start}

5x5 매트릭스를 사용합니다.

<BlockImage module="CheeseStick/HAT022" id="start" />

### 매개변수

(없음)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

---

## 건반 입력 값 {#key_input}

선택한 건반의 입력 상태  
건반이 눌려있으면 1, 건반이 눌려있지 않으면 0을 출력합니다.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### 매개변수

| 이름 | 구분 | 설명 | 범위 / 종류 | 기본값 |
| --- | --- | --- | --- | --- |
| unit | 드롭다운 옵션 | 음계 키 | 도(C), 도#(C#), 레(D), 레#(D#), 미(E), 파(F), 파#(F#), 솔(G), 솔#(G#), 라(A), 라#(A#), 시(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
