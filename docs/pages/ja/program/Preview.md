# プレビュー

**プレビュー**は、**ロボットの接続状態**を確認したり、コードやカメラ、コンソールなどロボットコーディングを補助する役割をする領域です。  
以下では、各タブで使える機能について説明します。

## ロボットの接続状態 {#robot-status}

<BlockImage module="program/Preview" id="robot-connected" /><br>

ロボットの接続状態のタブでは、現在接続されているロボットの情報を確認できます。   
**リアルタイムのセンサー値を表示**をクリックすると、ロボットのセンサーの値をグラフまたは数値でリアルタイムに確認できます。  

<BlockImage module="program/Preview" id="robot-sensor" /><br>

1. 参照するセンサーを選べます。ロボットごとに対応しているセンサーの種類が異なります。  
選んだセンサーに応じて、グラフやデータの表示方式がそのセンサーの値に合わせて自動的に変わります。 

2. センサーの値を何秒間隔で確認または記録するかを選べます。  
選んだ周期に応じて、データを記録してグラフに表示できる最大の時間が変わります。 
3. センサーのグラフの上にマウスを乗せると、その時点のセンサーの値をリアルタイムに一緒に確認できます。 
4. 記録の開始 / 停止: センサーのデータを記録します。 
5. エクスポート: 記録したセンサーのデータ(.csv)とグラフの画面(.png)をファイルとして保存します。  
この機能は、データを記録したあとにだけ使えます。 
6. キャプチャー: 現在のグラフの画面(.png)をリアルタイムに保存します。  
センサーの値の変化を記録して、記録したデータのファイルとグラフの画面をファイルとして保存できます。    

<br>

## Python プレビュー {#python-preview}

<BlockImage module="program/Preview" id="python-preview" /><br>

Python プレビューでは、ブロックを追加したり外したりするときに、どのように **Python** コードへ変換されるかをリアルタイムに確認できます。  
ブロックがどのようにコードへ変換されるかを一緒に確認しながら、より簡単にコーディングの文法を学べます。 

※ Python プレビューは**ブロックコーディングエディター**でのみ提供されます。  
Python エディターではユーザーが自分でコードを書くため、プレビューは提供されません。

<br>

## カメラ {#camera}

<BlockImage module="program/Preview" id="camera" /><br>

カメラのタブでは、PC に接続されたカメラの画面をリアルタイムに確認できます。  

この機能は、**カメラを使う拡張モジュールをプログラムに追加した場合**にだけ有効になり、カメラのタブにカメラモジュールが作られます。  

それぞれのカメラモジュールでは、次の機能を使えます。
- 現在の PC で使えるカメラの中から一つを選んで画面を表示できます。
- **オン / オフ**ボタンでカメラの画面を表示したり止めたりできます。
- **カメラの解像度**を変えられます。

<br>

## コンソール {#console}

コンソールのタブでは、プログラムの実行中に出力されるログ(Log)のメッセージとグラフ(Scope)をリアルタイムに確認できます。  
このタブは、デバッグやセンサーの値のモニタリング、グラフによる分析などに使われます。  

### ログ {#console-log}
**ログ出力**ブロックを使うと、指定したタグと一緒にテキストまたは数値をコンソールのログの領域に出力できます。   

<BlockImage module="program/Preview" id="console-log" /><br>


### グラフ {#console-scope}

**グラフ出力**ブロックを使うと、タグごとに数値を**リアルタイムのグラフ**で表現できます。  
最小値・最大値・グラフの色を設定して、見たい値の変化を視覚的に確認できます。
