# 上部メニュー

**上部メニュー**には、ドングルとロボットを接続したり、ファイルを保存して開いたりなど、プログラムでよく使われる機能が集まっています。  
以下では、各メニューの機能を順番に説明します。 

## ロゴ {#logo}

<BlockImage module="program/Menu" id="logo-block" /><br>

プログラムのロゴです。  
ロゴをクリックすると、ページが再読み込みされます。 

**ブロックコーディングエディター**が有効になると、ロゴの文が **Block Composer** と表示されます。  

<BlockImage module="program/Menu" id="logo-python" /><br>

**Python エディター**が有効になると、ロゴの文が **Script Composer** と表示されます。  

<br>

## ドングルを探す {#dongle}
<BlockImage module="program/Menu" id="dongle-button" /><br>

ロボットと通信する**ドングルを検索してプログラムに接続**できます。

プログラムでロボットを制御するには、ロボットと通信するドングルを先にプログラムへ接続する必要があります。  
この過程を**ペアリング**といいます。 

**ドングル**ボタンを押すと、現在の PC で使えるドングルの一覧が表示されます。  
一覧から使いたいドングルを選んだあと**接続**ボタンをクリックすると、ドングルがプログラムに接続されます。  

### ドングルの接続状態を確認する {#dongle-status}

一度プログラムに接続されたドングルは、それ以降プログラムを使うときに自動的に接続されます。

<BlockImage module="program/Menu" id="dongle-status-icon" /><br>


プログラムにドングルが正常に接続されている場合、アイコンが**水色**に変わります。  

<BlockImage module="program/Menu" id="dongle-status-browser" /><br> 

ブラウザーのタブに次の画像のようなアイコンがあれば、ドングルが接続された状態であることを確認できます。  

<br>

**⚠️ 注意事項**  

ドングルが別のプログラムまたは別のページにすでに接続されている場合、プログラムにドングルは接続されません。  
その場合は、ドングルが接続されているプログラムを見つけて接続を解除したあと、このページに戻ってもう一度接続を試してください。

<br>

## ロボットを選択 {#robot}
<BlockImage module="program/Menu" id="robot-button" /><br>  

プログラムで**使うロボットを選択**し、その**ロボットの情報と専用のブロック / スクリプトコードを登録**できます。 

プログラムでロボットを制御するには、使うロボットの情報とブロックを先にプログラムへ追加する必要があります。

<BlockImage module="program/Menu" id="robot-select" /><br>

**ロボット**ボタンを押すと、ポップアップにプログラムで使えるロボットの一覧が表示されます。  

使いたいロボットを選んだあと**追加**ボタンをクリックすると、そのロボットの情報と専用のブロック / スクリプトコードがプログラムに登録されます。  

<BlockImage module="program/Menu" id="robot-blocks" />  
<BlockImage module="program/Menu" id="robot-codes" /><br>   

ロボットが追加されると、次の項目が作られます。 


- **Block Composer**: 左の[**ブロックパレット**](Editor#block-editor)に、そのロボットの専用**ブロック**が作られます 
- **Script Composer**: 左の[**コードパレット**](Editor#python-editor)に、そのロボットの専用**スクリプトコード**が作られます

これによって、センサー・モーター・LED など実際のロボットのハードウェアを自由に動かして制御できます。  

<br>

**⚙️ 参考**

RobomationLAB では、ロボットの種類や台数に関係なく、好きなだけロボットを接続して使えます。  

ただし、複数台のロボットを同時に接続して使いたい場合は、使いたいロボットの台数だけドングルがプログラムに接続されている必要があり、使いたいロボットの台数だけロボットをプログラムに追加する必要があります。  

<br>

## 拡張機能を選択 {#extension}
<BlockImage module="program/Menu" id="extension-button" /><br>   

拡張モジュールは、**音声認識、映像認識、画像分析など AI ベースの拡張機能**を提供するモジュールです。  
プログラムで**使う拡張モジュールを選択**し、その**拡張モジュールの情報と専用のブロック / スクリプトコードを登録**できます。  

<BlockImage module="program/Menu" id="extension-select" /><br>

**拡張機能**ボタンを押すと、ポップアップにプログラムで使える拡張モジュールの一覧が表示された画面が現れます。  
- 音声テキスト変換
- 顔検出
- 詳細な顔検出
- 表情認識
- 手検出
- 身体検出
- 物体検出
- 色検出
- ArUco マーカー検出
- カメラ自動運転

使いたいモジュールをクリックすると、[**ロボットを選択**](#robot)と同じように、その拡張モジュールの情報と専用のブロック / スクリプトコードがプログラムに登録されます。 

**顔検出、手検出**などカメラを使う拡張モジュールをプログラムに追加すると、  
[**プレビュー - カメラ**](Preview#camera)タブにカメラモジュールが作られ、プログラムにカメラを接続して使えます。  

選んだ拡張モジュールがもう必要でない場合は、**右クリック → 削除**でロボットを一覧から外せます。

<br>

## サウンド {#sound}

<BlockImage module="program/Menu" id="sound-button" /><br>

コーディングに使う音を選んだり、オフラインにある音を自分でプログラムに追加したりできます。

### 音を選ぶ {#sound-select}
<BlockImage module="program/Menu" id="sound-select" /><br>

**サウンド**ボタンを押すと、プログラムが提供するさまざまな音を選べる画面が現れます。  
次のような機能を使えます。  
- 音の検索
- ▶ 音の試し聞き
- 音の一覧（左のパネル）への音の追加

### 拡張機能 {#sound-tools}
<BlockImage module="program/Menu" id="sound-tools" /><br>

左下の**拡張**ボタン（赤い枠）をクリックするかマウスを乗せると、3 つの拡張機能のオプションが現れます。  
次のような機能を使えます。
- ローカルファイルの追加: ユーザーのコンピューターにあるオーディオファイルを追加 
- 音の録音: 自分で録音して音を追加
- ランダムな音の追加: 音の一覧全体からランダムに選ばれた音を追加

### コーディングで音を使う {#sound-usage}
<BlockImage module="program/Menu" id="sound-selected" /><br>

音の一覧（左のパネル）に追加した音は、コーディングに使えます。

- **ブロックコーディング**の場合、**音を再生**ブロックのドロップダウンメニューから使いたい音を選べます。  

- **スクリプトコーディング**の場合、**コード - オーディオ**カテゴリーの **「音を再生」**関数の下位オプションから使いたい音を選べます。  

コードの実行時、選んだ音がユーザーのコンピューターのスピーカーから再生されます。

## 例 {#example}
<BlockImage module="program/Menu" id="example-button" /><br>    

プログラムにロボットが追加されている場合、ロボットごとに簡単なサンプルを読み込んで体験できます。

### サンプルを選ぶ {#example-select}
<BlockImage module="program/Menu" id="example-select" /><br>

例ボタンを押すと、上のような**サンプルを選択**の画面が現れます。   
**カテゴリーの区分**と**検索**の機能で、使いたいサンプルを素早く見つけられます。 

### サンプルを読み込む {#example-load}
1. **例**メニューをクリックして**サンプルを選択**の画面を開き、使いたいサンプルを選びます。 
2. 画面が再読み込みされ、サンプルがコーディング領域に現れます。   
3. サンプルを読み込んだあとは、ほかに何もせず**実行ボタン(▶)**を押して動作を確認できます。

## 編集 {#edit}

<BlockImage module="program/Menu" id="edit-button" />   

<BlockImage module="program/Menu" id="edit-menu" /><br>


作業を取り消したり、もう一度実行したりできる機能です。
- コピー (Ctrl+C): 選んだブロックまたはコードをコピーします。
- 貼り付け (Ctrl+V): コピーしたブロックまたはコードを作業領域に貼り付けます。

- やり直し (Ctrl+Y): 元に戻した作業をもう一度実行します。

## ファイル {#file}

<BlockImage module="program/Menu" id="file-button" />  

<BlockImage module="program/Menu" id="file-menu" /><br>

コードを新しく作ったり、書いたコードをファイルとして保存して開いたりなど、ファイルを管理できます。

- 新規作成  
現在書いているコードを初期化して、新しいコードを作ります。

- プロジェクトを保存  
現在作業しているプロジェクトファイルを保存します。  
ユーザーのコンピューターの「ダウンロード」フォルダーにファイルが保存され、ファイルの拡張子は「.block」です。

- Python コードをエクスポート  
現在作業しているプロジェクトの Python コードを抽出してファイルとして保存します。  
ユーザーのコンピューターの「ダウンロード」フォルダーにファイルが保存され、ファイルの拡張子は「.py」です。  
保存したファイルは、VSCode などの外部の Python 開発環境で開いて実行できます。

- プロジェクトを開く  
ユーザーのコンピューターにあるプロジェクトファイルまたは Python コードファイルを開きます。  
開けるファイルの拡張子は「.block」「.py」です。  
「.block」ファイルを開くとブロックコーディングエディターで開かれ、「.py」ファイルを開くと Python エディターで開かれます。  
「.py」ファイルを開くとき、BlockComposer のコード形式に合っていなかったり文法的な誤りがあると、ファイルが正常に開けないことがあるので注意してください。

<br>

## コードの実行 / 停止 {#run-stop}

### 実行 (▶) {#run}
<BlockImage module="program/Menu" id="run-button" /><br>

現在有効なエディターに書かれたブロックコードまたはスクリプトコードを解釈して実行します。  

書いたコードに応じて、プログラムに接続されたロボットを制御できます。  
コードの実行中は、書かれているコードを修正できません。

### 停止 (■) {#stop}
<BlockImage module="program/Menu" id="stop-button" /><br>

コードの実行を停止します。


<br>

## AI コーディング {#ai-coding}
<BlockImage module="program/Menu" id="ai-button" /><br>

上部メニューの **AI コーディング**ボタンを押すと、画面の右側に AI チャットボットのパネルが開きます。  
RobomationLAB に内蔵された **AI チャットボット**と会話しながら、AI と一緒にコーディングができます。

次のような機能を使えます。
- コードの書き方や直し方、文法、概念など、コーディングについて自由に質問できます。
- **コードの実行中にエラーが発生した場合**、AI にエラーが発生した理由と解決の方法を聞いて、素早く問題を解決できます。
- AI が提示したコードは、コードブロックの右にあるコピーボタンで簡単にコピーできます。
- 会話の内容は保存されて続けて会話でき、**新しい会話**を始めることもできます。
- パネルの左端をドラッグして、パネルの幅を調節できます。

<br>

## エディターの設定 {#editor-settings}
<BlockImage module="program/Menu" id="editor-button" /><br>

**ブロックコーディング**と **Python** のうち、使いたいエディターを選んでコーディングできます。  

エディターを変えても、以前に書いたコードはそのまま保たれるので、いつでも続けてコーディングできます。 

**※ ブロックコーディングエディターと Python エディターは 1 対 1 で対応し、エディターを切り替えると書いたコードが互いに変換されて引き継がれます。**

### ブロックコーディングエディター {#editor-settings-block}
ブロックコーディングを選ぶと、ロゴが **Block Composer**（ブロックコンポーザー）に変わります。  
ブロックコーディングエディターで書いたブロックはリアルタイムに Python コードへ変換され、**プレビュー - Python プレビュー**タブで変換の結果を確認できます。  

### Python エディター {#editor-settings-python}
Python を選ぶと、ロゴが **Script Composer**（スクリプトコンポーザー）に変わります。  
Python エディターで書いたコードは、もう一度**ブロックコーディングエディター**へ切り替えるときにブロックへ変換されます。  

> ただし、Python → ブロックの変換は、ブロックで表現できるコードに限って行われます。  
> 文法が誤っている場合やブロックに変換できないコードの場合は、ブロックコーディングエディターへ切り替わらないことがあり、その場合は切り替えが失敗した原因が一緒に表示されます。

<br>

## 設定 {#settings}
<BlockImage module="program/Menu" id="settings-button" />

<BlockImage module="program/Menu" id="settings-menu" /><br>

プログラムの基本設定を行えます。

### 言語 {#settings-language}
プログラムに表示される言語（国籍）を変更します。  
全 21 言語の中から使いたい言語を選べます。

### ドングル {#settings-dongle}
- 切断: プログラムに接続されたすべてのドングルの接続を解除します。
- 接続: プログラムにドングルをもう一度接続します。

### リセット {#settings-reset}
- プログラムをリセット: プログラムに登録されたすべてのデータ（ロボットの情報、ブロック / スクリプトコード、設定など）が初期化されます。
