# オーディオ

オーディオブロックを使うと、さまざまな効果音や音声を再生できます。


## 音を再生 {#play_sound}

好きな音を指定した**音量**で再生します。  
**繰り返し** チェックボックスを有効にすると、選んだ音を続けて繰り返し再生できます。

<BlockImage module="common/audio" id="play_sound" />

### パラメーター

| 名前 | 区分 | 説明 | 範囲・種類 | デフォルト値 |
| --- | --- | --- | --- | --- |
| clip | ドロップダウンオプション | サウンドクリップ名 | サウンドライブラリのクリップ名 | - |
| volume | 入力値（フィールド） | 音量 | 0 ~ 100 の整数 | 100 |
| repeat | チェックボックス | 繰り返し再生するかどうか | TRUE / FALSE | FALSE |

### Python
```python
Utils.play_sound('', 100, True)
Utils.play_sound('', 100, False)
```

## 言語と音声を設定 {#set_tts}

**TTS** を再生する**言語**と**音声**を設定します。  
さまざまな言語と音声を選ぶことで、より自然な音声を出力できます。

<BlockImage module="common/audio" id="set_tts" />

### パラメーター

| 名前 | 区分 | 説明 | 範囲・種類 | デフォルト値 |
| --- | --- | --- | --- | --- |
| lang | ドロップダウンオプション | 言語コード | プログラムが対応する 21 言語の TTS 言語コード（例: `'ja-JP'`, `'en-US'`） | - |
| voice | ドロップダウンオプション | 音声名 | システムの TTS 音声名（例: `'Google 日本語'`） | - |

### Python
```python
Utils.set_tts('ja-JP', '')
```

## 読み上げる {#speak}

入力されたテキストを音に変換して読み上げます。

<BlockImage module="common/audio" id="speak" />

### パラメーター

| 名前 | 区分 | 説明 | 範囲・種類 | デフォルト値 |
| --- | --- | --- | --- | --- |
| text | 入力値 | 読み上げるテキスト | 文字列 | - |

### Python
```python
Utils.speak('こんにちは')
```
