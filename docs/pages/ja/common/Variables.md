# 変数

変数という言葉は、数学やほかのプログラミング言語で使われるのと同じ意味で使います。  
つまり、**値を保存し、変更することができる、名前を持った要素**のことです。  
  
変数はいろいろな方法で作ることができます。  

- [カウントする](Loops#controls_for) や [各項目について](Loops#controls_forEach) のような一部のブロックは変数を使い、その変数の値を定義します。  
このような変数は、伝統的に **ループ変数（loop variables）** と呼ばれます。  
- [ユーザー定義関数](Functions#procedures_defnoreturn) も、パラメーターまたは引数を定義するために変数を使います。
- ユーザーは **変数をセット** ブロックでいつでも変数を作ることができ、作られた変数は **グローバル変数（global variables）** として宣言されます。  
- RobomationLAB のブロックコーディング環境では、**ローカル変数（local variables）** はサポートされていません。  

変数ブロックのドロップダウンをクリックすると、次のようなオプションが表示されます。  

- プログラムで定義されているすべての既存の変数名が表示されます。  
- **「変数の名前を変更」**: プログラム全体でその変数の名前を変更します。このオプションを選ぶと、新しい名前を入力する画面が表示されます。  
- **「変数を削除」**: プログラムでこの変数を参照しているすべてのブロックを削除します。 


## 変数をセット {#variables_set}

**変数をセット** ブロックは、変数に値を代入します。  
コード上でその変数が宣言されていない場合は、新しい変数を宣言してから値を代入します。   

<BlockImage module="common/variables" id="variables_set" />

### Python
```python
item = VAL
```

## 値を増やす {#math_change}

**増やす** ブロックは、変数の値に数値を足す働きをします。

<BlockImage module="common/variables" id="math_change" />

### Python
```python
item = item + 1
```



## 値を取得 {#variables_get}

次のブロックは変数に保存された値を提供しますが、その値を変更することはありません。  
セットブロックなしでこのブロックを使うこともできますが、それは正しいプログラミングの方法ではありません。

<BlockImage module="common/variables" id="variables_get" />

### Python
```python
item
```
