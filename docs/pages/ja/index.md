# RobomationLAB ユーザーガイド

**RobomationLAB** は AI ロボティクス SW 教育に最適化されたプラットフォームで、  
小学生・中学生を対象としたロボットコーディング教育のための Chrome ウェブブラウザーベースの統合オーサリング環境を提供します。

この文書では、プログラムが提供するすべてのブロックと Python コードの使い方について、詳しい説明を提供します。

**左のサイドバー**から見たいヘルプの項目を選んで確認できます。  
今、気になっている内容をすぐに確認してみてください。

## ブロック / Python ヘルプ

RobomationLAB は、ロボットコーディングに必要なさまざまな**基本ブロック**と、  
ロボメーションのロボットおよび拡張モジュールを制御できる**カスタムブロック**を提供します。  

すべてのブロックは、それぞれ決められた **Python コード**と 1 対 1 で対応し、自動的に変換されます。
