# HAT-022 タッチピアノ

## インスタンスの宣言 {#instance}

HAT-022 タッチピアノ(HAT022) ブロックを作業領域に追加すると、Python コードには次のようなインスタンスの宣言が自動的に挿入されます:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### パラメーター

| 名前 | 区分 | 説明 | 範囲・種類 | デフォルト値 |
| --- | --- | --- | --- | --- |
| index | ドロップダウンオプション | インスタンス番号（0 から始まる） | 0 以上の整数 | 0 |


## 開始 {#start}

タッチピアノを使います。

<BlockImage module="CheeseStick/HAT022" id="start" />

### パラメーター

（なし）

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## キーの入力 {#key_input}

選んだキーの入力の状態  
キーが押されていれば 1、キーが押されていなければ 0 を出力します。

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### パラメーター

| 名前 | 区分 | 説明 | 範囲・種類 | デフォルト値 |
| --- | --- | --- | --- | --- |
| unit | ドロップダウンオプション | 音階のキー | ド(C), ド#(C#), レ(D), レ#(D#), ミ(E), ファ(F), ファ#(F#), ソ(G), ソ#(G#), ラ(A), ラ#(A#), シ(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
