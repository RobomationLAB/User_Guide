# RobomationLAB User Guide

**RobomationLAB** is a platform optimized for AI robotics SW education,  
providing a Chrome web browser based integrated authoring environment for robot coding education aimed at elementary and middle school students.

This documentation provides detailed explanations of how to use every block and every piece of Python code the program provides.

You can pick the help topic you want from the **sidebar on the left**.  
Go ahead and look up whatever you are curious about right now.

## Block / Python Help

along with **custom blocks** that let you control Robomation's robots and extension modules.  

Every block corresponds one-to-one to a defined piece of **Python code** and is converted automatically.
