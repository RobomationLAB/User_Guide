# HAT-022 aanraakpiano

## Instantie declareren {#instance}

Voeg je een HAT-022 aanraakpiano(HAT022)-blok toe aan het werkgebied, dan wordt in de Python-code automatisch de volgende instantiedeclaratie ingevoegd:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parameters

| Naam | Soort | Beschrijving | Bereik / Type | Standaardwaarde |
| --- | --- | --- | --- | --- |
| index | Keuzelijstoptie | Instantienummer (begint bij 0) | geheel getal ≥ 0 | 0 |


## Aanraakpiano starten {#start}

Gebruikt de aanraakpiano.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parameters

(geen)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Toetsinvoer {#key_input}

De invoertoestand van de gekozen pianotoets  
Is de toets ingedrukt, dan wordt 1 uitgevoerd, is die niet ingedrukt, dan 0.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parameters

| Naam | Soort | Beschrijving | Bereik / Type | Standaardwaarde |
| --- | --- | --- | --- | --- |
| unit | Keuzelijstoptie | Toets van de toonladder | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
