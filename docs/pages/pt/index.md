# Guia do utilizador do RobomationLAB

O **RobomationLAB** é uma plataforma otimizada para o ensino de software de robótica com IA  
e oferece um ambiente de autoria integrado baseado no navegador Chrome para o ensino de programação de robôs a alunos do ensino básico.

Este documento oferece descrições detalhadas da forma de usar todos os blocos e códigos Python que o programa oferece.

Na **barra lateral esquerda** podes escolher e abrir o tópico de ajuda que queres.  
Vê agora mesmo o que te interessa.

**blocos personalizados** com que podes controlar os robôs e os módulos de extensão da Robomation.  

Todos os blocos correspondem um a um a um **código Python** determinado e são convertidos automaticamente.
