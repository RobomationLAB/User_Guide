# HAT-022 Piano táctil

## Declarar la instancia {#instance}

Si añades un bloque de HAT-022 Piano táctil(HAT022) al área de trabajo, en el código Python se inserta automáticamente la declaración de instancia siguiente:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parámetros

| Nombre | Tipo | Descripción | Rango / Tipo | Valor predeterminado |
| --- | --- | --- | --- | --- |
| index | Opción de desplegable | Número de instancia (empieza en 0) | entero ≥ 0 | 0 |


## Iniciar el piano táctil {#start}

Usa el piano táctil.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parámetros

(ninguno)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Entrada de la tecla {#key_input}

El estado de entrada de la tecla elegida  
Si la tecla está pulsada, se devuelve 1; si no está pulsada, 0.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parámetros

| Nombre | Tipo | Descripción | Rango / Tipo | Valor predeterminado |
| --- | --- | --- | --- | --- |
| unit | Opción de desplegable | Tecla de la escala | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
