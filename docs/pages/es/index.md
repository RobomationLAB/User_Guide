# Guía del usuario de RobomationLAB

**RobomationLAB** es una plataforma optimizada para la enseñanza de software de robótica con IA.  
Ofrece un entorno de autoría integrado basado en el navegador web Chrome para la enseñanza de programación de robots a alumnos de primaria y secundaria.

Esta guía describe en detalle cómo se usan todos los bloques y códigos Python del programa.

En la **barra lateral izquierda** puedes elegir el tema de ayuda que quieras.  
Consulta ahora mismo lo que te interese.

## Ayuda de bloques / Python

**bloques propios** con los que puedes controlar los robots y las extensiones de Robomation.  

Todos los bloques se corresponden uno a uno con un **código Python** definido y se convierten automáticamente.
