# HAT-022 berøringsklaver

## Instanserklæring {#instance}

Når du tilføjer en HAT-022 berøringsklaver(HAT022)-blok i arbejdsområdet, indsættes følgende instanserklæring automatisk i Python-koden:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parametre

| Navn | Slags | Beskrivelse | Interval / Type | Standard |
| --- | --- | --- | --- | --- |
| index | Rullemenupunkt | Instansnummer (starter ved 0) | Heltal 0 eller større | 0 |


## Start berøringsklaveret {#start}

Begynder at bruge berøringsklaveret.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parametre

(ingen)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Tastens inputværdi {#key_input}

Inputtilstanden for den valgte tast  
Den giver 1, når tasten er trykket ned, og 0, når den ikke er.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parametre

| Navn | Slags | Beskrivelse | Interval / Type | Standard |
| --- | --- | --- | --- | --- |
| unit | Rullemenupunkt | Tonetast | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
