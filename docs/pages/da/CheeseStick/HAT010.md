# HAT-010 5x5-matrix

## Instanserklæring {#instance}

Når du tilføjer en HAT-010 5x5-matrix(HAT010)-blok i arbejdsområdet, indsættes følgende instanserklæring automatisk i Python-koden:

```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()
```

### Parametre

| Navn | Slags | Beskrivelse | Interval / Type | Standard |
| --- | --- | --- | --- | --- |
| index | Rullemenupunkt | Instansnummer (starter ved 0) | Heltal 0 eller større | 0 |


## Start LED-matrixen {#start}

Begynder at bruge 5x5-matrixen.

<BlockImage module="CheeseStick/HAT010" id="start" />

### Parametre

(ingen)

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.start()
```

<BlockImage module="CheeseStick/HAT010" id="set_one" />

### Parametre

| Navn | Slags | Beskrivelse | Interval / Type | Standard |
| --- | --- | --- | --- | --- |
| x | Input (felt) | Vandret koordinat | Heltal 0 til 4 | - |
| y | Input (felt) | Lodret koordinat | Heltal 0 til 4 | - |

### Python

## Flyt matrixen {#shift}

Flytter billedet så mange felter i x- og y-retning, som du angiver.  
En positiv x-værdi flytter billedet til højre, en negativ til venstre.  
En positiv y-værdi flytter billedet ned, en negativ op.

<BlockImage module="CheeseStick/HAT010" id="shift" />

### Parametre

| Navn | Slags | Beskrivelse | Interval / Type | Standard |
| --- | --- | --- | --- | --- |
| x | Input (felt) | Flytning i bredden | Heltal | - |
| y | Input (felt) | Flytning i højden | Heltal | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.shift(1, 0)
```

## Knappens inputværdi {#button_input}

Inputtilstanden for den valgte knap  
Den giver 0, når knappen er trykket ned, og 1, når den ikke er.

<BlockImage module="CheeseStick/HAT010" id="button_input" />

### Parametre

| Navn | Slags | Beskrivelse | Interval / Type | Standard |
| --- | --- | --- | --- | --- |
| unit | Rullemenupunkt | Knappens navn | knap A(A), knap B(B) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.button_input('A')
```

## Blev der klikket på knappen? {#button_click}
