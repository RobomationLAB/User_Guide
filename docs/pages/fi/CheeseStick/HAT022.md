# HAT-022 kosketuspiano

## Instanssin esittely {#instance}

Kun lisäät HAT-022 kosketuspiano(HAT022)-lohkon työtilaan, Python-koodiin lisätään automaattisesti seuraava instanssin esittely:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parametrit

| Nimi | Laji | Kuvaus | Alue / Tyyppi | Oletus |
| --- | --- | --- | --- | --- |
| index | Pudotusvalikon vaihtoehto | Instanssin numero (alkaa nollasta) | Kokonaisluku 0 tai suurempi | 0 |


## Käynnistä kosketuspiano {#start}

Ottaa kosketuspianon käyttöön.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parametrit

(ei mitään)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Näppäimen tuloarvo {#key_input}

Valitsemasi näppäimen tulotila  
Se antaa 1, kun näppäin on painettuna, ja 0, kun ei ole.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parametrit

| Nimi | Laji | Kuvaus | Alue / Tyyppi | Oletus |
| --- | --- | --- | --- | --- |
| unit | Pudotusvalikon vaihtoehto | Nuottinäppäin | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
