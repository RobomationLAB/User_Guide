# HAT-010 Matrice 5x5

## Dichiarare l'istanza {#instance}

Se aggiungi un blocco di HAT-010 Matrice 5x5 (HAT010) all'area di lavoro, nel codice Python viene inserita automaticamente la dichiarazione di istanza seguente:

```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()
```

### Parametri

| Nome | Tipo | Descrizione | Intervallo / Tipo | Valore predefinito |
| --- | --- | --- | --- | --- |
| index | Opzione di elenco | Numero dell'istanza (parte da 0) | intero maggiore o uguale a 0 | 0 |


## Avviare la matrice di LED {#start}

Usa la matrice 5x5.

<BlockImage module="CheeseStick/HAT010" id="start" />

### Parametri

(nessuno)

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.start()
```

## Accendere un punto {#set_one}

Imposta il colore del LED nella posizione indicata.  
La posizione del LED si indica con le coordinate x, y.

<BlockImage module="CheeseStick/HAT010" id="set_one" />

### Parametri

| Nome | Tipo | Descrizione | Intervallo / Tipo | Valore predefinito |
| --- | --- | --- | --- | --- |
| x | Ingresso (campo) | Coordinata orizzontale | intero 0 ~ 4 | - |
| y | Ingresso (campo) | Coordinata verticale | intero 0 ~ 4 | - |
| color | Opzione di elenco | Colore | spento(off), rosso(red), arancione(orange), giallo(yellow), verde(green), ciano(cyan), blu(blue), viola(violet), magenta(magenta), bianco(white) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.set_one(2, 3, 'red')
```

## Spostare la matrice {#shift}

Sposta l'immagine della x e della y indicate.  
Se il valore di x è positivo l'immagine si sposta a destra, se è negativo si sposta a sinistra.  
Se il valore di y è positivo l'immagine si sposta in basso, se è negativo si sposta in alto.

<BlockImage module="CheeseStick/HAT010" id="shift" />

### Parametri

| Nome | Tipo | Descrizione | Intervallo / Tipo | Valore predefinito |
| --- | --- | --- | --- | --- |
| x | Ingresso (campo) | Spostamento orizzontale | intero | - |
| y | Ingresso (campo) | Spostamento verticale | intero | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.shift(1, 0)
```

## Valore di ingresso del pulsante {#button_input}

Lo stato di ingresso del pulsante scelto  
Restituisce 0 se il pulsante è premuto e 1 se non lo è.

<BlockImage module="CheeseStick/HAT010" id="button_input" />

### Parametri

| Nome | Tipo | Descrizione | Intervallo / Tipo | Valore predefinito |
| --- | --- | --- | --- | --- |
| unit | Opzione di elenco | Nome del pulsante | pulsante A(A), pulsante B(B) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.button_input('A')
```

## Il pulsante è stato cliccato? {#button_click}

Se il pulsante scelto è stato cliccato  
Questo blocco restituisce true solo nel momento in cui il pulsante scelto viene cliccato; negli altri casi restituisce false.

<BlockImage module="CheeseStick/HAT010" id="button_click" />

### Parametri

| Nome | Tipo | Descrizione | Intervallo / Tipo | Valore predefinito |
| --- | --- | --- | --- | --- |
| unit | Opzione di elenco | Nome del pulsante | pulsante A(A), pulsante B(B) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.button_click('A')
```
