# HAT-022 Pianoforte touch

## Dichiarare l'istanza {#instance}

Se aggiungi un blocco di HAT-022 Pianoforte touch (HAT022) all'area di lavoro, nel codice Python viene inserita automaticamente la dichiarazione di istanza seguente:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parametri

| Nome | Tipo | Descrizione | Intervallo / Tipo | Valore predefinito |
| --- | --- | --- | --- | --- |
| index | Opzione di elenco | Numero dell'istanza (parte da 0) | intero maggiore o uguale a 0 | 0 |


## Avviare il pianoforte touch {#start}

Usa il pianoforte touch.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parametri

(nessuno)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Valore di ingresso del tasto {#key_input}

Lo stato di ingresso del tasto scelto  
Restituisce 1 se il tasto è premuto e 0 se non lo è.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parametri

| Nome | Tipo | Descrizione | Intervallo / Tipo | Valore predefinito |
| --- | --- | --- | --- | --- |
| unit | Opzione di elenco | Tasto della nota | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
