# Piobot

## การประกาศอินสแตนซ์ {#instance}

เมื่อเพิ่มบล็อก Piobot(Pio) ลงในพื้นที่ทำงาน การประกาศอินสแตนซ์ต่อไปนี้จะถูกแทรกลงในโค้ด Python โดยอัตโนมัติ:

```python
pio = Pio(0)
# กรณีที่มีหลายอินสแตนซ์
pio_1 = Pio(1)
```

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| index | ตัวเลือกดรอปดาวน์ | หมายเลขอินสแตนซ์ (เริ่มจาก 0) | จำนวนเต็ม 0 ขึ้นไป | 0 |


## ตั้งความเร็วล้อ {#set_wheel_speed}

ตั้งความเร็วของล้อ ช่วงความเร็วล้อคือ -100 ~ 100

<BlockImage module="roboids/Pio" id="set_wheel_speed" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| unit | ตัวเลือกดรอปดาวน์ | ล้อที่เลือก | ซ้าย(left), ขวา(right), ทั้งคู่(both) | - |
| speed | ค่าป้อนเข้า (บล็อก) | ความเร็วล้อ | จำนวนเต็ม -100 ~ 100, 0: หยุด | - |

### Python
```python
pio = Pio(0)

pio.set_wheel_speed('both', 50)
```

## เคลื่อนที่ตามระยะทาง {#move_distance}

เคลื่อนที่ตามระยะทางที่กำหนดด้วยความเร็วล้อปัจจุบัน  
ถ้ายังไม่ได้ตั้งความเร็วล้อ จะเคลื่อนที่ไปข้างหน้าด้วยความเร็วเริ่มต้น  
ถ้าค่าระยะทางเป็น 0 จะเคลื่อนที่ต่อไปตามความเร็วล้อปัจจุบัน  
ถ้าทำเครื่องหมายที่ รอ จะรอจนกว่าการเคลื่อนที่จะเสร็จสิ้น

<BlockImage module="roboids/Pio" id="move_distance" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| data | ค่าป้อนเข้า (บล็อก) | ระยะทางที่เคลื่อนที่ | จำนวนจริง 0 ขึ้นไป | - |
| unit | ตัวเลือกดรอปดาวน์ | หน่วยระยะทาง | ซม.(cm), มม.(mm), นิ้ว(inch) | cm |
| wait | ช่องทำเครื่องหมาย | รอจนเสร็จสิ้นหรือไม่ | TRUE / FALSE | TRUE |

### Python
```python
pio = Pio(0)

pio.move_distance(50, 'cm', wait=True)
```

## เคลื่อนที่เป็นเวลา {#move_time}

เคลื่อนที่เป็นเวลาที่กำหนดด้วยความเร็วล้อปัจจุบัน  
ถ้ายังไม่ได้ตั้งความเร็วล้อ จะเคลื่อนที่ไปข้างหน้าด้วยความเร็วเริ่มต้น  
ถ้าทำเครื่องหมายที่ รอ จะรอจนกว่าการเคลื่อนที่จะเสร็จสิ้น

<BlockImage module="roboids/Pio" id="move_time" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| data | ค่าป้อนเข้า (บล็อก) | เวลาที่เคลื่อนที่ (วินาที) | จำนวนจริง 0 ขึ้นไป | - |
| wait | ช่องทำเครื่องหมาย | รอจนเสร็จสิ้นหรือไม่ | TRUE / FALSE | TRUE |

### Python
```python
pio = Pio(0)

# wait = TRUE
pio.move_time(5, wait=True)
# wait = FALSE
pio.move_time(5, wait=False)
```

## หมุนอยู่กับที่ {#turn_degree}

กำหนดทิศทางและมุมที่จะหมุนอยู่กับที่  
ถ้าทำเครื่องหมายที่ รอ จะรอจนกว่าการหมุนจะเสร็จสิ้น

<BlockImage module="roboids/Pio" id="turn_degree" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| direction | ตัวเลือกดรอปดาวน์ | ทิศทางการหมุน | ซ้าย(left), ขวา(right) | - |
| data | ค่าป้อนเข้า (บล็อก) | มุมที่หมุน (องศา) | จำนวนจริง 0 ขึ้นไป | - |
| wait | ช่องทำเครื่องหมาย | รอจนเสร็จสิ้นหรือไม่ | TRUE / FALSE | TRUE |

### Python
```python
pio = Pio(0)

# direction = "left"
pio.turn_degree('left', 90, wait=True)
# direction = "right"
pio.turn_degree('right', 90, wait=True)
```

## ตั้งสีไฟ LED ที่ตา {#set_eye_color}

ตั้งสีไฟ LED ที่ตาของ Piobot  
เปลี่ยนสีไฟ LED ของตาซ้าย ตาขวา หรือทั้งคู่ได้  
เมื่อเลือกสีจากสีพรีเซ็ต จะถูกแปลงเป็น **ชื่อสี** (สตริงภาษาอังกฤษ) แล้วเรียกใช้ (โค้ดที่สร้างขึ้นใช้ชื่อสี ไม่ใช่ค่าตัวเลข R, G, B)

<BlockImage module="roboids/Pio" id="set_eye_color" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| unit | ตัวเลือกดรอปดาวน์ | ตาที่เลือก | ซ้าย(left), ขวา(right), ทั้งคู่(both) | - |
| color | ตัวเลือกดรอปดาวน์ | สีพรีเซ็ต → แปลงเป็นชื่อสี (ภาษาอังกฤษ) | ดำ(black), แดง(red), เหลือง(yellow), เขียว(green), ฟ้าอมเขียว(cyan), น้ำเงิน(blue), ม่วงแดง(magenta), ขาว(white) | - |

### Python
```python
pio = Pio(0)

pio.set_eye_color('both', 'red')
```

## เล่นคลิปเสียง {#sound_clip}

Piobot เล่นคลิปเสียงที่กำหนด  
ถ้าทำเครื่องหมายที่ รอ จะรอจนกว่าการเล่นจะเสร็จสิ้น

<BlockImage module="roboids/Pio" id="sound_clip" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| clip | ตัวเลือกดรอปดาวน์ | ชื่อคลิปเสียง | `'mute'`, `'beep'`, `'beep2'`, `'beep3'`, `'siren'`, `'engine'`, `'robot'`, `'connect'` ฯลฯ | - |
| wait | ช่องทำเครื่องหมาย | รอจนเสร็จสิ้นหรือไม่ | TRUE / FALSE | TRUE |

### Python
```python
pio = Pio(0)

pio.sound_clip('siren', wait=True)
```
