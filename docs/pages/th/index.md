# คู่มือการใช้งาน RobomationLAB

**RobomationLAB** เป็นแพลตฟอร์มที่ออกแบบมาเพื่อการศึกษาซอฟต์แวร์ AI โรโบติกส์โดยเฉพาะ  
และให้สภาพแวดล้อมการสร้างงานแบบบูรณาการบนเว็บเบราว์เซอร์ Chrome สำหรับการศึกษาการเขียนโค้ดหุ่นยนต์ของนักเรียนระดับประถมและมัธยมต้น

เอกสารนี้ให้คำอธิบายโดยละเอียดเกี่ยวกับวิธีใช้บล็อกและโค้ด Python ทั้งหมดที่โปรแกรมมีให้

สามารถเลือกหัวข้อความช่วยเหลือที่ต้องการได้จาก **แถบด้านข้างทางซ้าย**  
ลองดูเนื้อหาที่สงสัยอยู่ตอนนี้ได้เลย

- [คู่มือการเขียนโค้ด](guide/CodingGuide)
- [กฎการเขียนโค้ด](guide/CodingRules)

RobomationLAB ประกอบด้วยองค์ประกอบที่มีความสามารถหลากหลายซึ่งจำเป็นต่อการเขียนโค้ดหุ่นยนต์  
องค์ประกอบเหล่านี้แบ่งออกเป็นหมวดหมู่ดังนี้:

## ความช่วยเหลือเรื่องบล็อก / Python

RobomationLAB มี **บล็อกพื้นฐาน** หลากหลายที่จำเป็นต่อการเขียนโค้ดหุ่นยนต์  
และ **บล็อกเฉพาะ** ที่ควบคุมหุ่นยนต์และโมดูลส่วนขยายของ Robomation ได้  

บล็อกทั้งหมดสอดคล้องแบบหนึ่งต่อหนึ่งกับ **โค้ด Python** ที่กำหนดไว้ และถูกแปลงโดยอัตโนมัติ
