# การรู้จำเสียงพูด

## การประกาศอินสแตนซ์ {#instance}

เมื่อเพิ่มบล็อกการรู้จำเสียงพูด (ASR) ลงในพื้นที่ทำงาน การประกาศอินสแตนซ์ต่อไปนี้จะถูกแทรกลงในโค้ด Python โดยอัตโนมัติ:

```python
asr = ASR(0)
# กรณีที่มีหลายอินสแตนซ์
asr_1 = ASR(1)
```

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| index | ตัวเลือกดรอปดาวน์ | หมายเลขอินสแตนซ์ (เริ่มจาก 0) | จำนวนเต็ม 0 ขึ้นไป | 0 |


## ตั้งค่าภาษา {#lang}

ตั้งภาษาสำหรับการรู้จำเสียงพูด แม้ไม่ได้ตั้งค่าภาษา ระบบก็จะตั้งให้โดยอัตโนมัติ

<BlockImage module="AI/ASR" id="lang" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| unit | ตัวเลือกดรอปดาวน์ | รหัสภาษาที่รู้จำ | รหัสของ 21 ภาษาที่โปรแกรมรองรับ (เช่น `'th-TH'`, `'en-US'`) | - |

### Python
```python
asr = ASR(0)

asr.lang('th-TH')
```

## เริ่ม / หยุดการรู้จำเสียงพูด {#listen}

เริ่มหรือหยุดการรู้จำเสียงพูด

<BlockImage module="AI/ASR" id="listen" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| unit | ตัวเลือกดรอปดาวน์ | การทำงาน | เริ่ม(start), หยุด(stop) | - |

### Python
```python
asr = ASR(0)

# unit = "start"
asr.start()
# unit = "stop"
asr.stop()
```
