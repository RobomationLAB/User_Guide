# CSD-07 เซ็นเซอร์เสียง

## การประกาศอินสแตนซ์ {#instance}

เมื่อเพิ่มบล็อก CSD-07 เซ็นเซอร์เสียง (CSD07) ลงในพื้นที่ทำงาน การประกาศอินสแตนซ์ต่อไปนี้จะถูกแทรกลงในโค้ด Python โดยอัตโนมัติ:

```python
cheesestick = CheeseStick(0)
csd07 = cheesestick.CSD07()
```

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| index | ตัวเลือกดรอปดาวน์ | หมายเลขอินสแตนซ์ (เริ่มจาก 0) | จำนวนเต็ม 0 ขึ้นไป | 0 |


## เริ่มด้วยพอร์ต {#set_input_port}

ตั้งพอร์ตที่ CSD07 (เซ็นเซอร์เสียง) เชื่อมต่ออยู่

<BlockImage module="CheeseStick/CSD07" id="set_input_port" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| unit | ตัวเลือกดรอปดาวน์ | พอร์ตที่จะเชื่อมต่อ | Sa, Sb, Sc | - |

### Python
```python
cheesestick = CheeseStick(0)
csd07 = cheesestick.CSD07()

csd07.set_port('Sa')
```

## ค่าเซ็นเซอร์เสียง {#get_input}

ค่าเซ็นเซอร์เสียงของพอร์ตที่เลือก

<BlockImage module="CheeseStick/CSD07" id="get_input" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| unit | ตัวเลือกดรอปดาวน์ | พอร์ตที่จะอ่าน | Sa, Sb, Sc | พอร์ตของ `set_port` ครั้งล่าสุด |

### Python
```python
cheesestick = CheeseStick(0)
csd07 = cheesestick.CSD07()

csd07.get_input('Sa')
```
