# อื่น ๆ

ในการเขียนโค้ดด้วยบล็อก **บล็อกอื่น ๆ** ประกอบด้วยโค้ดที่ไม่มีผลต่อการทำงานของหุ่นยนต์  
ใช้เขียนความคิดเห็น (คอมเมนต์) หรือจบการทำงานของโค้ดได้  

## ความคิดเห็นบรรทัดเดียว {#comment}

บล็อก **ความคิดเห็นบรรทัดเดียว** ใช้เพิ่ม **คำอธิบาย** โดยไม่มีผลต่อการทำงานของโค้ด  
การใช้ความคิดเห็นช่วยให้อ่านโค้ดง่ายขึ้นและดูแลรักษาได้สะดวกขึ้น

<BlockImage module="common/others" id="comment" />

### Python
```python
# เนื้อหาความคิดเห็น
```

## ความคิดเห็นหลายบรรทัด {#long_comment}

บล็อก **ความคิดเห็นหลายบรรทัด** ใช้ป้อนความคิดเห็นหลายบรรทัดได้ในครั้งเดียว  
แต่ละบรรทัดจะได้เครื่องหมายความคิดเห็นโดยอัตโนมัติ และบรรทัดว่างจะคงไว้ตามเดิม

<BlockImage module="common/others" id="long_comment" />

### Python
```python
"""
บรรทัดที่หนึ่ง
บรรทัดที่สอง

บรรทัดที่สี่
"""
```

## ลิงก์ {#link}

บล็อก **ลิงก์** ใช้เพิ่ม **ลิงก์ของหน้าเว็บ** ที่ต้องการเปิดในรูปแบบ **ความคิดเห็น**  
เมื่อคลิกปุ่ม **เปิด** จะไปยังหน้าเว็บของลิงก์ที่ป้อนไว้

<BlockImage module="common/others" id="link" />

### Python
```python
# https://example.com
```

## ออก {#exit}

บล็อก **ออก** จะหยุดการทำงานของโค้ดในโปรแกรมทันที  
มีประโยชน์เมื่อต้องการเพิ่มการบังคับจบโปรแกรมภายใต้เงื่อนไขที่กำหนด

<BlockImage module="common/others" id="exit" />

### Python
```python
Utils.exit()
```
