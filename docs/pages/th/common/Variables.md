# ตัวแปร

เราใช้คำว่าตัวแปรในความหมายเดียวกับที่ใช้ในคณิตศาสตร์และภาษาโปรแกรมอื่น ๆ  
กล่าวคือ **องค์ประกอบที่มีชื่อ ซึ่งเก็บค่าและเปลี่ยนค่าได้**  
  
ตัวแปรสร้างได้หลายวิธี  

- บล็อกบางตัว เช่น [นับด้วย](Loops#controls_for) และ [จากทุกรายการ](Loops#controls_forEach) ใช้ตัวแปรและกำหนดค่าให้ตัวแปรนั้น  
ตัวแปรเหล่านี้เรียกกันโดยทั่วไปว่า **ตัวแปรลูป (loop variables)**  
- [ฟังก์ชันที่ผู้ใช้กำหนด](Functions#procedures_defnoreturn) ก็ใช้ตัวแปรในการกำหนดพารามิเตอร์หรืออาร์กิวเมนต์เช่นกัน
- ผู้ใช้สร้างตัวแปรได้ทุกเมื่อผ่านบล็อก **กำหนดตัวแปร** และตัวแปรที่สร้างจะถูกประกาศเป็น **ตัวแปรส่วนกลาง (global variables)**  
- สภาพแวดล้อมการเขียนโค้ดด้วยบล็อกของ RobomationLAB ไม่รองรับ **ตัวแปรท้องถิ่น (local variables)**  

เมื่อคลิกดรอปดาวน์ของบล็อกตัวแปร จะมีตัวเลือกดังนี้  

- แสดงชื่อตัวแปรทั้งหมดที่กำหนดไว้ในโปรแกรม  
- **"เปลี่ยนชื่อตัวแปร"**: เปลี่ยนชื่อตัวแปรนั้นทั่วทั้งโปรแกรม เมื่อเลือกตัวเลือกนี้จะมีหน้าต่างให้ป้อนชื่อใหม่  
- **"ลบตัวแปร"**: ลบบล็อกทั้งหมดที่อ้างถึงตัวแปรนี้ออกจากโปรแกรม 


## กำหนดตัวแปร {#variables_set}

บล็อก **กำหนด** จะกำหนดค่าให้กับตัวแปร  
ถ้ายังไม่ได้ประกาศตัวแปรนั้นในโค้ด จะประกาศตัวแปรใหม่ก่อนแล้วจึงกำหนดค่า   

<BlockImage module="common/variables" id="variables_set" />

### Python
```python
item = VAL
```

## เปลี่ยนค่า {#math_change}

บล็อก **เปลี่ยนค่า** จะบวกตัวเลขเข้ากับค่าของตัวแปร

<BlockImage module="common/variables" id="math_change" />

### Python
```python
item = item + 1
```



## เรียกดูค่า {#variables_get}

บล็อกด้านล่างจะให้ค่าที่เก็บอยู่ในตัวแปร แต่ไม่เปลี่ยนแปลงค่านั้น  
สามารถใช้บล็อกนี้โดยไม่มีบล็อกกำหนดค่าได้ แต่ไม่ใช่วิธีเขียนโปรแกรมที่ถูกต้อง

<BlockImage module="common/variables" id="variables_get" />

### Python
```python
item
```
