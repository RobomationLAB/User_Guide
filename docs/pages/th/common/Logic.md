# ตรรกะ

บล็อกตรรกะโดยทั่วไปใช้ควบคุมบล็อก **เงื่อนไข** และบล็อก [**ลูป**](Loops)

## เงื่อนไข (ถ้า ~ ทำ) {#controls_if}

บล็อกเงื่อนไขใช้กำหนด **เงื่อนไข** และ **การทำงาน** ที่จะเกิดขึ้นเมื่อเงื่อนไขนั้นเป็นจริง

<BlockImage module="common/logic" id="controls_if" />

ตัวอย่างเช่น สามารถเขียนโค้ดได้ดังนี้  
ถ้าค่าของตัวแปร **x** มากกว่า 100 เงื่อนไขจะเป็น **จริง** และจะแสดงข้อความ "เป็นจำนวนที่มาก"  
ถ้าค่าของ **x** ไม่มากกว่า 100 เงื่อนไขจะเป็น **เท็จ** และจะแสดงข้อความ "เป็นจำนวนที่ไม่มาก"

### Python
```python
if condition:
  # ...
elif condition2:
  # ...
else:
  # ...
```

## การเปรียบเทียบ {#logic_compare}

มีตัวดำเนินการเปรียบเทียบอยู่ 6 แบบ  
แต่ละตัวรับค่าป้อนเข้า 2 ค่า (โดยทั่วไปเป็นตัวเลข) แล้วคืนค่าจริงหรือเท็จตามผลการเปรียบเทียบของค่าทั้งสอง

<BlockImage module="common/logic" id="logic_compare" />

### Python
```python
A == B
A != B
A < B
A <= B
A > B
A >= B
```

## การดำเนินการทางตรรกะ {#logic_operation}

บล็อก **และ** คืนค่าจริงเมื่อค่าป้อนเข้าทั้งสองเป็นจริงเท่านั้น  
บล็อก **หรือ** คืนค่าจริงเมื่อค่าป้อนเข้าอย่างน้อยหนึ่งค่าเป็นจริง  

<BlockImage module="common/logic" id="logic_operation" />

### Python
```python
A and B
A or B
```

## ไม่ {#logic_negate}

บล็อก **ไม่** จะกลับค่าบูลีนที่ป้อนเข้าให้เป็นค่าตรงข้าม  

<BlockImage module="common/logic" id="logic_negate" />

### Python
```python
not A
```

## บูลีน {#logic_boolean}

สามารถรับค่าบูลีนได้จากบล็อกเดียวที่มีดรอปดาวน์สำหรับเลือก **จริง** หรือ **เท็จ**  

<BlockImage module="common/logic" id="logic_boolean" />

### Python
```python
True
False
```

## ตัวดำเนินการสามทาง {#logic_ternary}

บล็อกสามทางทำงานเหมือนบล็อกเงื่อนไขแบบง่าย  
รับค่าป้อนเข้า 3 ค่า  
ค่าแรกคือเงื่อนไขบูลีนที่จะทดสอบ ค่าที่สองคือค่าที่จะคืนเมื่อเงื่อนไขเป็น **จริง**  
ค่าที่สามคือค่าที่จะคืนเมื่อเงื่อนไขเป็น **เท็จ**  

<BlockImage module="common/logic" id="logic_ternary" />

### Python
```python
thenValue if test else elseValue
```
