# ฟังก์ชัน

**ฟังก์ชัน (Function)** คือ **กลุ่มของคำสั่ง (บล็อก)** ที่ทำงานอย่างใดอย่างหนึ่ง  
เมื่อกำหนดการทำงานที่ใช้ซ้ำบ่อย ๆ เป็นฟังก์ชันเดียว จะจัดการโค้ดได้ **กระชับและมีประสิทธิภาพ** ยิ่งขึ้น

ฟังก์ชันมีลักษณะดังนี้  
- **ใช้ซ้ำได้**: กำหนดครั้งเดียว เรียกใช้ได้หลายครั้ง  
- **มีอินพุตและเอาต์พุต**: รับพารามิเตอร์ (ค่าป้อนเข้า) มาประมวลผล แล้วคืนผลลัพธ์ (ค่าส่งออก) ได้  
- **อ่านโค้ดง่ายขึ้น**: จัดโครงสร้างลำดับการทำงานของโปรแกรมได้อย่างเป็นเหตุเป็นผล


## setup {#setup}

**ฟังก์ชัน setup** จะถูกเรียกเพียงครั้งเดียวในตอนที่เริ่มรันโค้ด  
ในฟังก์ชัน setup มักเขียนโค้ดสำหรับกำหนดค่าเริ่มต้นของตัวแปร หรือตั้งค่าโหมดและตัวเลือกของหุ่นยนต์  
ตัวอย่างเช่น เมื่อควบคุมหุ่นยนต์ที่เคลื่อนที่ด้วยล้อ สามารถตั้งความเร็วเริ่มต้นของล้อในฟังก์ชัน setup ได้  

<BlockImage module="common/functions" id="setup" />
  
เมื่อใช้ฟังก์ชัน `Utils.wait(...)` จะเขียนโค้ดที่ทำงานตามลำดับเวลาแบบต่อเนื่องได้ และเมื่อใช้ร่วมกับ **ฟังก์ชัน loop** ซึ่งทำหน้าที่ทำงานแบบขนาน จะเขียนโปรแกรมหุ่นยนต์ได้อย่างทรงพลัง ไม่ใช่เพียงการทำงานตามลำดับแบบง่ายเท่านั้น  

### Python
```python
def setup():
    # ...
    return
```

## loop {#loop}

**ฟังก์ชัน loop** จะถูกเรียกซ้ำทุก 10ms ตลอดเวลาที่โปรแกรมทำงาน  
ในฟังก์ชัน loop มักเขียนโค้ดสำหรับตั้งค่าตัวแปรซ้ำ ๆ หรือตรวจจับและจัดการเหตุการณ์ที่เกิดขึ้นกับหุ่นยนต์

<BlockImage module="common/functions" id="loop" />

### Python
```python
def loop():
    # ...
    return
```

## กำหนดฟังก์ชัน {#procedures_defnoreturn}

ใช้บล็อกกำหนดฟังก์ชันเพื่อสร้าง **ฟังก์ชันใหม่** ได้  
ฟังก์ชันที่ไม่มีค่าคืนจะทำงานอย่างใดอย่างหนึ่ง แต่ **ไม่คืนค่า**

<BlockImage module="common/functions" id="procedures_defnoreturn" />

### Python
```python
def myFunction(arg1, arg2):
    # ...
```

## กำหนดฟังก์ชันที่มีค่าคืน {#procedures_defreturn}

ฟังก์ชันที่มีค่าคืนจะทำงานอย่างใดอย่างหนึ่งแล้ว **คืนค่า** ผลลัพธ์ เพื่อนำไปใช้ในบล็อกอื่นได้  

<BlockImage module="common/functions" id="procedures_defreturn" />

ฟังก์ชันด้านล่าง **รับพารามิเตอร์ x, y แล้วคืนผลลัพธ์ของ x + y**  

### Python
```python
def myFunction(x, y):
    return x + y
```

## เรียกใช้ฟังก์ชัน {#procedures_callnoreturn}

เมื่อกำหนดฟังก์ชันแล้ว **บล็อกฟังก์ชันที่ผู้ใช้กำหนด** จะถูกสร้างขึ้นโดยอัตโนมัติ  
ใช้บล็อกนี้เรียกใช้ **ฟังก์ชันที่กำหนดไว้ล่วงหน้า** ได้

<BlockImage module="common/functions" id="procedures_callnoreturn" />

### Python
```python
myFunction(arg1, arg2)
```

## ถ้า ... คืนค่า {#procedures_ifreturn}

บล็อกที่ **คืนค่าทันทีเมื่อเงื่อนไขที่กำหนดเป็นจริง** และจบการทำงานของฟังก์ชัน  
บล็อกนี้ **ใช้ได้เฉพาะภายในฟังก์ชัน** และจะถูกปิดใช้งานเมื่ออยู่ที่อื่น

<BlockImage module="common/functions" id="procedures_ifreturn" />

### Python
```python
if condition:
    return value
```
