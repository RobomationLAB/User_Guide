# ควบคุม

ในการเขียนโค้ดด้วยบล็อก **บล็อกควบคุม** มีหน้าที่จัดการลำดับการทำงานของโปรแกรม  
ใช้รอเป็นระยะเวลาหนึ่ง ตรวจจับการกดแป้นพิมพ์ แสดงบันทึก (log) และอื่น ๆ ได้


## รอ {#wait_sec}

รอตามเวลาที่กำหนด (วินาที) แล้วจึงทำคำสั่งถัดไป

<BlockImage module="common/control" id="wait_sec" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| sec | ค่าป้อนเข้า (ฟิลด์) | เวลารอ — **ตัวเลขลิเทอรัล** (เช่น `Utils.wait(0.5)`) | จำนวนจริง 0 ขึ้นไป | - |
| sec | ค่าป้อนเข้า (บล็อก) | เวลารอ — **ตัวแปร/นิพจน์** (เช่น `Utils.wait(time)`) | จำนวนจริง 0 ขึ้นไป | - |

### Python
```python
# ฟิลด์ sec = 2 → ใช้ตามเดิม (หน่วยวินาที)
Utils.wait(2)

# ป้อนด้วยตัวแปร
Utils.wait(myVar)
```

<BlockImage module="common/control" id="wait_1msec" />

## กดปุ่ม {#key_pressed}

คืนค่า **จริง (True) / เท็จ (False)** ว่าปุ่มที่กำหนดถูกกดอยู่หรือไม่

<BlockImage module="common/control" id="key_pressed" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| key | ค่าป้อนเข้า | ชื่อปุ่ม | space, up, left, right, down, a~z, 0~9,<br>shift, ctrl, alt, enter, tab, esc, backspace | - |

### Python
```python
Utils.keypressed('space')
```

## บันทึก (log) {#log}

แสดงค่าของตัวแปรหรือคุณสมบัติที่กำหนดในหน้าต่าง **คอนโซล** แบบเรียลไทม์

<BlockImage module="common/control" id="log" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| data | ค่าป้อนเข้า | ค่าที่จะแสดง | ค่าใดก็ได้ | - |
| tag | ค่าป้อนเข้า | แท็กของบันทึก | สตริง | - |
| unit | ค่าป้อนเข้า | หน่วยที่แสดง | สตริง | - |

### Python
```python
Utils.log(data, '', '')
```

## กราฟ (scope) {#scope}

แสดงการเปลี่ยนแปลงของค่าที่กำหนดเป็นกราฟแบบเรียลไทม์ในหน้าต่าง **สโคป**  
กำหนดสี ค่าต่ำสุด/สูงสุด และช่วงของกราฟได้

<BlockImage module="common/control" id="scope" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| signal | ค่าป้อนเข้า (บล็อก) | ค่าสัญญาณของกราฟ | จำนวนจริง | - |
| name | ค่าป้อนเข้า | ชื่อกราฟ | สตริง | - |
| min_val | ค่าป้อนเข้า (ฟิลด์) | ค่าต่ำสุดของกราฟ | จำนวนจริง | - |
| max_val | ค่าป้อนเข้า (ฟิลด์) | ค่าสูงสุดของกราฟ | จำนวนจริง | - |
| color | สี | สีของกราฟ (hex) | สตริง hex | - |

### Python
```python
Utils.scope(signal, '', 0, 100, '#000000')
```
