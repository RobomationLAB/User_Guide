# สี

สีถูกใช้ในโปรแกรมกราฟิกหลากหลายประเภท 


## สีพื้นฐาน {#color_picker}

วิธีที่ง่ายที่สุดในการเลือกสีคือใช้ **จานสี**  
เมื่อคลิกสี่เหลี่ยมมุมมนสีขาว จานสีจะปรากฏขึ้น และสามารถเลือกสีที่ต้องการได้

<BlockImage module="common/color" id="color_picker" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| color | สี | สีพรีเซ็ต | สีดำ(black), สีแดง(red), สีเหลือง(yellow), สีเขียว(green),<br>สีฟ้าอมเขียว(cyan), สีน้ำเงิน(blue), สีม่วงแดง(magenta), สีขาว(white) | - |

### Python
```python
# ตัวอย่าง: เมื่อเลือกพรีเซ็ตสีแดง
Utils.color('red')
```

## สีจากแถบเลื่อน {#color_slider}

บล็อก **สีจากแถบเลื่อน** ใช้ผสมสีได้เองด้วยแถบเลื่อนแบบวงกลม / แบบแท่ง  
เมื่อคลิกสี่เหลี่ยมมุมมนสีขาว จะปรากฏวงล้อสีสำหรับปรับค่า **แดง (R), เขียว (G), น้ำเงิน (B)** และแถบเลื่อนแบบแท่งสำหรับปรับ **ความสว่าง**

<BlockImage module="common/color" id="color_slider" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| color | สี | วงล้อสี + แถบเลื่อนความสว่าง | r: 0~255, g: 0~255, b: 0~255 | - |

### Python
```python
# สีที่เลือกจากวงล้อสี → [R, G, B]
Utils.color_slider(255, 128, 0)
```

## สี RGB {#color_rgb}

บล็อก **สี RGB** จะสร้างอาร์เรย์ RGB โดยกำหนดค่าแดง เขียว น้ำเงินแยกกัน

<BlockImage module="common/color" id="color_rgb" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| r | ค่าป้อนเข้า (บล็อก) | ค่าสีแดง | จำนวนเต็ม 0 ~ 255 | - |
| g | ค่าป้อนเข้า (บล็อก) | ค่าสีเขียว | จำนวนเต็ม 0 ~ 255 | - |
| b | ค่าป้อนเข้า (บล็อก) | ค่าสีน้ำเงิน | จำนวนเต็ม 0 ~ 255 | - |

### Python
```python
Utils.color_rgb(red, green, blue)
```
