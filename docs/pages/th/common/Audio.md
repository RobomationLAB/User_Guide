# เสียง

บล็อกเสียงใช้เล่นเสียงประกอบและเสียงพูดได้หลากหลาย


## เล่นเสียง {#play_sound}

เล่นเสียงที่ต้องการด้วย **ระดับเสียง** ที่กำหนด  
เมื่อเปิดใช้ช่องทำเครื่องหมาย **เล่นซ้ำ** เสียงที่เลือกจะถูกเล่นซ้ำไปเรื่อย ๆ

<BlockImage module="common/audio" id="play_sound" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| clip | ตัวเลือกดรอปดาวน์ | ชื่อคลิปเสียง | ชื่อคลิปในคลังเสียง | - |
| volume | ค่าป้อนเข้า (ฟิลด์) | ระดับเสียง | จำนวนเต็ม 0 ~ 100 | 100 |
| repeat | ช่องทำเครื่องหมาย | เล่นซ้ำหรือไม่ | TRUE / FALSE | FALSE |

### Python
```python
Utils.play_sound('', 100, True)
Utils.play_sound('', 100, False)
```

## ตั้งค่าภาษาและเสียง {#set_tts}

ตั้งค่า **ภาษา** และ **เสียง** ที่จะใช้เล่น **TTS**  
เลือกภาษาและเสียงได้หลากหลายเพื่อให้เสียงพูดเป็นธรรมชาติยิ่งขึ้น

<BlockImage module="common/audio" id="set_tts" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| lang | ตัวเลือกดรอปดาวน์ | รหัสภาษา | รหัสภาษา TTS ของ 21 ภาษาที่โปรแกรมรองรับ (เช่น `'th-TH'`, `'en-US'`) | - |
| voice | ตัวเลือกดรอปดาวน์ | ชื่อเสียง | ชื่อเสียง TTS ของระบบ (เช่น `'Google ไทย'`) | - |

### Python
```python
Utils.set_tts('th-TH', '')
```

## พูด {#speak}

แปลงข้อความที่ป้อนเข้าเป็นเสียงพูด

<BlockImage module="common/audio" id="speak" />

### พารามิเตอร์

| ชื่อ | ประเภท | คำอธิบาย | ช่วง / ชนิด | ค่าเริ่มต้น |
| --- | --- | --- | --- | --- |
| text | ค่าป้อนเข้า | ข้อความที่จะพูด | สตริง | - |

### Python
```python
Utils.speak('สวัสดี')
```
