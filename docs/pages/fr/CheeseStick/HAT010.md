# HAT-010 Matrice 5x5

## Déclarer l'instance {#instance}

Si tu ajoutes un bloc de HAT-010 Matrice 5x5 (HAT010) à la zone de travail, la déclaration d'instance suivante est insérée automatiquement dans le code Python :

```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()
```

### Paramètres

| Nom | Type | Description | Plage / Type | Valeur par défaut |
| --- | --- | --- | --- | --- |
| index | Option de liste | Numéro de l'instance (commence à 0) | entier supérieur ou égal à 0 | 0 |

<BlockImage module="CheeseStick/HAT010" id="set_one" />

| Nom | Type | Description | Plage / Type | Valeur par défaut |

```python
])
```

## Déplacer la matrice {#shift}

Déplace l'image du x et du y indiqués.  
Si la valeur de x est positive, l'image se déplace vers la droite ; si elle est négative, vers la gauche.  
Si la valeur de y est positive, l'image se déplace vers le bas ; si elle est négative, vers le haut.

<BlockImage module="CheeseStick/HAT010" id="shift" />

### Paramètres

| Nom | Type | Description | Plage / Type | Valeur par défaut |
| --- | --- | --- | --- | --- |
| x | Entrée (champ) | Déplacement horizontal | entier | - |
| y | Entrée (champ) | Déplacement vertical | entier | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.shift(1, 0)
```
