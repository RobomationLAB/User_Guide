# HAT-022 Piano tactile

## Déclarer l'instance {#instance}

Si tu ajoutes un bloc de HAT-022 Piano tactile (HAT022) à la zone de travail, la déclaration d'instance suivante est insérée automatiquement dans le code Python :

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Paramètres

| Nom | Type | Description | Plage / Type | Valeur par défaut |
| --- | --- | --- | --- | --- |
| index | Option de liste | Numéro de l'instance (commence à 0) | entier supérieur ou égal à 0 | 0 |


## Démarrer le piano tactile {#start}

Utilise le piano tactile.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Paramètres

(aucun)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Valeur d'entrée de la touche {#key_input}

L'état d'entrée de la touche choisie  
Renvoie 1 si la touche est pressée et 0 sinon.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Paramètres

| Nom | Type | Description | Plage / Type | Valeur par défaut |
| --- | --- | --- | --- | --- |
| unit | Option de liste | Touche de la note | Do(C), Do#(C#), Ré(D), Ré#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
