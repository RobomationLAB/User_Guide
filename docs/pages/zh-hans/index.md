# RobomationLAB 用户指南

**RobomationLAB** 是一个为 AI 机器人 SW 教育优化的平台，  
为面向小学生和初中生的机器人编程教育提供基于 Chrome 浏览器的集成创作环境。

本文档详细说明程序提供的所有积木和 Python 代码的使用方法。

可以在 **左侧边栏** 选择想看的帮助项目来查看。  
现在就来确认你关心的内容吧。
