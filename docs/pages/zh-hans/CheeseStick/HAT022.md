# HAT-022 触摸钢琴

## 声明实例 {#instance}

把 HAT-022 触摸钢琴(HAT022) 积木添加到工作区后，Python 代码中会自动插入下面这样的实例声明：

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### 参数

| 名称 | 类别 | 说明 | 范围 / 种类 | 默认值 |
| --- | --- | --- | --- | --- |
| index | 下拉选项 | 实例编号（从 0 开始） | 0 以上的整数 | 0 |


## 启动 {#start}

开始使用触摸钢琴。

<BlockImage module="CheeseStick/HAT022" id="start" />

### 参数

（无）

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## 按键 {#key_input}

所选琴键的输入状态  
琴键被按下时输出 1，没有被按下时输出 0。

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### 参数

| 名称 | 类别 | 说明 | 范围 / 种类 | 默认值 |
| --- | --- | --- | --- | --- |
| unit | 下拉选项 | 音符键 | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
