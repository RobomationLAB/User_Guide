# HAT-022 Dokunmatik Piyano

## Örnek bildirimi {#instance}

HAT-022 Dokunmatik Piyano(HAT022) bloğunu çalışma alanına eklediğinizde Python koduna aşağıdaki örnek bildirimi kendiliğinden eklenir:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parametreler

| Ad | Tür | Açıklama | Aralık / Tip | Varsayılan |
| --- | --- | --- | --- | --- |
| index | Açılır liste seçeneği | Örnek numarası (0'dan başlar) | 0 veya daha büyük tam sayı | 0 |


## Dokunmatik piyanoyu başlat {#start}

Dokunmatik piyanoyu kullanılabilir duruma getirir.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parametreler

(yok)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Tuş giriş değeri {#key_input}

Seçilen tuşun giriş durumu  
Tuşa basılıysa 1, basılı değilse 0 döndürür.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parametreler

| Ad | Tür | Açıklama | Aralık / Tip | Varsayılan |
| --- | --- | --- | --- | --- |
| unit | Açılır liste seçeneği | Nota tuşu | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
