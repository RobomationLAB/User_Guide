# HAT-010 5x5-matrise

## Instanserklæring {#instance}

Når du legger til en HAT-010 5x5-matrise(HAT010)-blokk i arbeidsområdet, settes følgende instanserklæring automatisk inn i Python-koden:

```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()
```

### Parametere

| Navn | Slag | Beskrivelse | Område / Type | Standard |
| --- | --- | --- | --- | --- |
| index | Nedtrekksalternativ | Instansnummer (starter på 0) | Heltall 0 eller større | 0 |


## Start LED-matrisen {#start}

Tar 5x5-matrisen i bruk.

<BlockImage module="CheeseStick/HAT010" id="start" />

### Parametere

(ingen)

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.start()
```

## Slå på ett punkt {#set_one}

Angir fargen på LED-en i den posisjonen du velger.  
LED-posisjonen oppgis som x- og y-koordinater.

<BlockImage module="CheeseStick/HAT010" id="set_one" />

### Parametere

| Navn | Slag | Beskrivelse | Område / Type | Standard |
| --- | --- | --- | --- | --- |
| x | Inndata (felt) | Vannrett koordinat | Heltall 0 til 4 | - |
| y | Inndata (felt) | Loddrett koordinat | Heltall 0 til 4 | - |
| color | Nedtrekksalternativ | Farge | av(off), rød(red), oransje(orange), gul(yellow), grønn(green), cyan(cyan), blå(blue), fiolett(violet), magenta(magenta), hvit(white) | - |

### Python
```python

hat010 = cheesestick.HAT010()

hat010.set_one(2, 3, 'red')
```

## Flytt matrisen {#shift}

Flytter skjermbildet så mange x og y som du angir.  
Er x positiv, flyttes bildet mot høyre, og er den negativ, flyttes det mot venstre.  
Er y positiv, flyttes bildet nedover, og er den negativ, flyttes det oppover.

<BlockImage module="CheeseStick/HAT010" id="shift" />

### Parametere

| Navn | Slag | Beskrivelse | Område / Type | Standard |
| --- | --- | --- | --- | --- |
| x | Inndata (felt) | Vannrett flytting | Heltall | - |
| y | Inndata (felt) | Loddrett flytting | Heltall | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.shift(1, 0)
```

## Knappens inngangsverdi {#button_input}

Inngangstilstanden til den knappen du velger  
Den gir 0 når knappen er trykket ned, og 1 når den ikke er det.

<BlockImage module="CheeseStick/HAT010" id="button_input" />

### Parametere

| Navn | Slag | Beskrivelse | Område / Type | Standard |
| --- | --- | --- | --- | --- |
| unit | Nedtrekksalternativ | Knappenavn | knapp A(A), knapp B(B) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.button_input('A')
```

## Ble knappen klikket? {#button_click}
