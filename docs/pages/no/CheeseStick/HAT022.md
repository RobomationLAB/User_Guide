# HAT-022 berøringspiano

## Instanserklæring {#instance}

Når du legger til en HAT-022 berøringspiano(HAT022)-blokk i arbeidsområdet, settes følgende instanserklæring automatisk inn i Python-koden:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parametere

| Navn | Slag | Beskrivelse | Område / Type | Standard |
| --- | --- | --- | --- | --- |
| index | Nedtrekksalternativ | Instansnummer (starter på 0) | Heltall 0 eller større | 0 |


## Start berøringspianoet {#start}

Tar berøringspianoet i bruk.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parametere

(ingen)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Tastens inngangsverdi {#key_input}

Inngangstilstanden til den tasten du velger  
Den gir 1 når tasten er trykket ned, og 0 når den ikke er det.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parametere

| Navn | Slag | Beskrivelse | Område / Type | Standard |
| --- | --- | --- | --- | --- |
| unit | Nedtrekksalternativ | Tonetast | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
