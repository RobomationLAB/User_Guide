# HAT-010 5x5-matris

## Instansdeklaration {#instance}

När du lägger till ett HAT-010 5x5-matris(HAT010)-block i arbetsytan infogas följande instansdeklaration automatiskt i Python-koden:

```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()
```

### Parametrar

| Namn | Sort | Beskrivning | Intervall / Typ | Standard |
| --- | --- | --- | --- | --- |
| index | Rullgardinsalternativ | Instansnummer (börjar på 0) | Heltal 0 eller större | 0 |


## Starta LED-matrisen {#start}

Börjar använda 5x5-matrisen.

<BlockImage module="CheeseStick/HAT010" id="start" />

### Parametrar

(ingen)

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.start()
```

## Tända en punkt {#set_one}

Ställer in färgen på lysdioden i den angivna positionen.  
Lysdiodens position anges med x- och y-koordinater.

<BlockImage module="CheeseStick/HAT010" id="set_one" />

### Parametrar

| Namn | Sort | Beskrivning | Intervall / Typ | Standard |
| --- | --- | --- | --- | --- |
| x | Inmatning (fält) | Vågrät koordinat | Heltal 0 till 4 | - |
| y | Inmatning (fält) | Lodrät koordinat | Heltal 0 till 4 | - |
| color | Rullgardinsalternativ | Färg | av(off), röd(red), orange(orange), gul(yellow), grön(green), cyan(cyan), blå(blue), violett(violet), magenta(magenta), vit(white) | - |

### Python
```python

hat010.set_one(2, 3, 'red')
```

## Flytta matrisen {#shift}

Flyttar bilden så många steg i x- och y-led som du anger.  
Ett positivt x-värde flyttar bilden åt höger, ett negativt åt vänster.  
Ett positivt y-värde flyttar bilden nedåt, ett negativt uppåt.

<BlockImage module="CheeseStick/HAT010" id="shift" />

### Parametrar

| Namn | Sort | Beskrivning | Intervall / Typ | Standard |
| --- | --- | --- | --- | --- |
| x | Inmatning (fält) | Förflyttning i sidled | Heltal | - |
| y | Inmatning (fält) | Förflyttning i höjdled | Heltal | - |

### Python
```python
cheesestick = CheeseStick(0)
hat010 = cheesestick.HAT010()

hat010.shift(1, 0)
```

<BlockImage module="CheeseStick/HAT010" id="button_input" />

### Parametrar

| Namn | Sort | Beskrivning | Intervall / Typ | Standard |
| --- | --- | --- | --- | --- |

