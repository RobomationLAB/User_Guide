# HAT-022 touchpiano

## Instansdeklaration {#instance}

När du lägger till ett HAT-022 touchpiano(HAT022)-block i arbetsytan infogas följande instansdeklaration automatiskt i Python-koden:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parametrar

| Namn | Sort | Beskrivning | Intervall / Typ | Standard |
| --- | --- | --- | --- | --- |
| index | Rullgardinsalternativ | Instansnummer (börjar på 0) | Heltal 0 eller större | 0 |


## Starta touchpianot {#start}

Börjar använda touchpianot.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parametrar

(ingen)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Tangentens ingångsvärde {#key_input}

Ingångstillståndet för den valda tangenten  
Det ger 1 när tangenten är nedtryckt och 0 när den inte är det.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parametrar

| Namn | Sort | Beskrivning | Intervall / Typ | Standard |
| --- | --- | --- | --- | --- |
| unit | Rullgardinsalternativ | Tontangent | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
