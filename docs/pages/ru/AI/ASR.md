# Распознавание речи

## Объявление экземпляра {#instance}

После добавления блока Распознавание речи(ASR) в рабочую область в код Python автоматически вставляется следующее объявление экземпляра:

```python
asr = ASR(0)
# Когда экземпляров несколько
asr_1 = ASR(1)
```

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| index | Пункт выпадающего списка | Номер экземпляра (начиная с 0) | Целое число 0 или больше | 0 |


## Установить язык {#lang}

Задаёт язык распознавания речи. Даже без настройки язык подбирается автоматически.

<BlockImage module="AI/ASR" id="lang" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| unit | Пункт выпадающего списка | Код языка распознавания | Коды 21 языка, поддерживаемого программой (например, `'ru-RU'`, `'en-US'`) | - |

### Python
```python
asr = ASR(0)

asr.lang('ru-RU')
```

## Запустить / остановить распознавание речи {#listen}

Запускает или останавливает распознавание речи.

<BlockImage module="AI/ASR" id="listen" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| unit | Пункт выпадающего списка | Действие | запустить(start), остановить(stop) | - |

### Python
```python
asr = ASR(0)

# unit = "start"
asr.start()
# unit = "stop"
asr.stop()
```

## Распознавание речи активно {#state}

Возвращает **истину (True) или ложь (False)** в зависимости от того, активно ли распознавание речи.

<BlockImage module="AI/ASR" id="state" />

### Параметры

(нет)

### Python
```python
asr = ASR(0)

asr.is_active()
```
