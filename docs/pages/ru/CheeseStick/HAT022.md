# HAT-022 Сенсорное пианино

## Объявление экземпляра {#instance}

После добавления блока HAT-022 Сенсорное пианино(HAT022) в рабочую область в код Python автоматически вставляется следующее объявление экземпляра:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| index | Пункт выпадающего списка | Номер экземпляра (начиная с 0) | Целое число 0 или больше | 0 |


## Запустить сенсорное пианино {#start}

Включает сенсорное пианино.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Параметры

(нет)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Вход клавиши {#key_input}

Состояние входа выбранной клавиши  
Возвращает 1, если клавиша нажата, и 0, если нет.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| unit | Пункт выпадающего списка | Клавиша ноты | До(C), До#(C#), Ре(D), Ре#(D#), Ми(E), Фа(F), Фа#(F#), Соль(G), Соль#(G#), Ля(A), Ля#(A#), Си(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
