# CSD-07 Датчик звука

## Объявление экземпляра {#instance}

После добавления блока CSD-07 Датчик звука(CSD07) в рабочую область в код Python автоматически вставляется следующее объявление экземпляра:

```python
cheesestick = CheeseStick(0)
csd07 = cheesestick.CSD07()
```

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| index | Пункт выпадающего списка | Номер экземпляра (начиная с 0) | Целое число 0 или больше | 0 |


## Задать порт входа {#set_input_port}

Задаёт порт, к которому подключён модуль CSD07 (датчик звука).

<BlockImage module="CheeseStick/CSD07" id="set_input_port" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| unit | Пункт выпадающего списка | Порт для подключения | Sa, Sb, Sc | - |

### Python
```python
cheesestick = CheeseStick(0)
csd07 = cheesestick.CSD07()

csd07.set_port('Sa')
```

## Значение датчика звука {#get_input}

Значение датчика звука с выбранного порта

<BlockImage module="CheeseStick/CSD07" id="get_input" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| unit | Пункт выпадающего списка | Порт для чтения | Sa, Sb, Sc | порт из последнего `set_port` |

### Python
```python
cheesestick = CheeseStick(0)
csd07 = cheesestick.CSD07()

csd07.get_input('Sa')
```
