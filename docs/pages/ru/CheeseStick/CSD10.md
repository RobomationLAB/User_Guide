# CSD-10 Датчик освещённости

## Объявление экземпляра {#instance}

После добавления блока CSD-10 Датчик освещённости(CSD10) в рабочую область в код Python автоматически вставляется следующее объявление экземпляра:

```python
cheesestick = CheeseStick(0)
csd10 = cheesestick.CSD10()
```

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| index | Пункт выпадающего списка | Номер экземпляра (начиная с 0) | Целое число 0 или больше | 0 |


## Задать порт входа {#set_input_port}

Задаёт порт, к которому подключён модуль CSD10 (датчик освещённости).

<BlockImage module="CheeseStick/CSD10" id="set_input_port" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| unit | Пункт выпадающего списка | Порт для подключения | Sa, Sb, Sc | - |

### Python
```python
cheesestick = CheeseStick(0)
csd10 = cheesestick.CSD10()

csd10.set_port('Sa')
```

## Значение датчика освещённости {#get_input}

Значение датчика освещённости с выбранного порта

<BlockImage module="CheeseStick/CSD10" id="get_input" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| unit | Пункт выпадающего списка | Порт для чтения | Sa, Sb, Sc | порт из последнего `set_port` |

### Python
```python
cheesestick = CheeseStick(0)
csd10 = cheesestick.CSD10()

csd10.get_input('Sa')
```
