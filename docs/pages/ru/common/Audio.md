# Аудио

Звуковые блоки позволяют воспроизводить разные звуковые эффекты и речь.


## Воспроизвести звук {#play_sound}

Воспроизводит выбранный звук с заданной **громкостью**.  
Если установить флажок **повторять**, выбранный звук будет воспроизводиться снова и снова.

<BlockImage module="common/audio" id="play_sound" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| clip | Пункт выпадающего списка | Название звукового клипа | Названия клипов из библиотеки звуков | - |
| volume | Ввод (поле) | Громкость | Целое число от 0 до 100 | 100 |
| repeat | Флажок | Воспроизводить ли по кругу | TRUE / FALSE | FALSE |

### Python
```python
Utils.play_sound('', 100, True)
Utils.play_sound('', 100, False)
```

## Задать язык и голос {#set_tts}

Задаёт **язык** и **голос**, которыми воспроизводится **речь (TTS)**.  
Выбирая разные языки и голоса, можно добиться более естественного звучания.

<BlockImage module="common/audio" id="set_tts" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| lang | Пункт выпадающего списка | Код языка | Коды языков TTS для 21 языка, поддерживаемого программой (например, `'ru-RU'`, `'en-US'`) | - |
| voice | Пункт выпадающего списка | Название голоса | Название голоса TTS в системе (например, `'Google русский'`) | - |

### Python
```python
Utils.set_tts('ru-RU', '')
```

## Произнести {#speak}

Превращает введённый текст в речь и произносит его.

<BlockImage module="common/audio" id="speak" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| text | Ввод | Текст для произнесения | Строка | - |

### Python
```python
Utils.speak('Здравствуйте')
```
