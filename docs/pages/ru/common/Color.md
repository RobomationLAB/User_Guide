# Цвет

Цвета используются во многих графических программах. 


## Базовый цвет {#color_picker}

Самый простой способ получить цвет — воспользоваться **палитрой цветов**.  
По нажатию на белый скруглённый квадрат появляется палитра, из которой можно выбрать цвет.

<BlockImage module="common/color" id="color_picker" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| color | Цвет | Готовый цвет | чёрный(black), красный(red), жёлтый(yellow), зелёный(green),<br>голубой(cyan), синий(blue), пурпурный(magenta), белый(white) | - |

### Python
```python
# пример: при выборе готового красного цвета
Utils.color('red')
```

## Цвет ползунка {#color_slider}

Блок **цвет ползунка** позволяет самостоятельно составить цвет с помощью круга и ползунка.  
По нажатию на белый скруглённый квадрат появляются цветовой круг, на котором задаются значения **красного (R), зелёного (G) и синего (B)**, и ползунок **яркости**.

<BlockImage module="common/color" id="color_slider" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| color | Цвет | Цветовой круг + ползунок яркости | r: 0~255, g: 0~255, b: 0~255 | - |

### Python
```python
# цвет, выбранный на цветовом круге → [R, G, B]
Utils.color_slider(255, 128, 0)
```

## Цвет RGB {#color_rgb}

Блок **цвет RGB** создаёт массив RGB из отдельно заданных значений красного, зелёного и синего.

<BlockImage module="common/color" id="color_rgb" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| r | Ввод (блок) | Значение красного | Целое число от 0 до 255 | - |
| g | Ввод (блок) | Значение зелёного | Целое число от 0 до 255 | - |
| b | Ввод (блок) | Значение синего | Целое число от 0 до 255 | - |

### Python
```python
Utils.color_rgb(red, green, blue)
```
