# Переменные

Термин «переменная» мы используем в том же значении, что и в математике и других языках программирования.  
Это **именованный элемент, который хранит значение и позволяет его менять**.  
  
Переменные создаются несколькими способами.  

- Некоторые блоки, например [цикл по](Loops#controls_for) и [для каждого элемента](Loops#controls_forEach), используют переменную и сами задают её значение.  
Такие переменные традиционно называют **переменными цикла (loop variables)**.  
- [Пользовательские функции](Functions#procedures_defnoreturn) тоже используют переменные для описания параметров, то есть аргументов.
- Пользователь может создать переменную в любой момент блоком **присвоить**; созданная так переменная объявляется как **глобальная переменная (global variable)**.  
- Среда блочного программирования RobomationLAB не поддерживает **локальные переменные (local variables)**.  

При нажатии на выпадающий список в блоке переменной появляются следующие пункты.  

- Имена всех переменных, определённых в программе.  
- **«Переименовать переменную»**: меняет имя этой переменной во всей программе. После выбора этого пункта появляется окно для ввода нового имени.  
- **«Удалить переменную»**: удаляет из программы все блоки, которые ссылаются на эту переменную. 


## Присвоить {#variables_set}

Блок **присвоить** задаёт переменной значение.  
Если такой переменной в коде ещё нет, он сначала объявляет новую переменную, а затем присваивает ей значение.   

<BlockImage module="common/variables" id="variables_set" />

### Python
```python
item = VAL
```

## Увеличить {#math_change}

Блок **увеличить** прибавляет число к значению переменной.

<BlockImage module="common/variables" id="math_change" />

### Python
```python
item = item + 1
```



## Получить значение {#variables_get}

Блок ниже выдаёт значение, хранящееся в переменной, но не меняет его.  
Использовать этот блок без блока присваивания можно, но это не лучший способ программирования.

<BlockImage module="common/variables" id="variables_get" />

### Python
```python
item
```
