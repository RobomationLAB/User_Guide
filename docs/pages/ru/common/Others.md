# Другое

В блочном программировании **блоки из категории Другое** — это код, который не влияет на работу робота.  
Они позволяют добавлять комментарии или завершать выполнение кода.  

## Однострочный комментарий {#comment}

Блок **однострочный комментарий** позволяет добавить **пояснение**, не влияющее на выполнение кода.  
Комментарии делают код понятнее и облегчают его поддержку.

<BlockImage module="common/others" id="comment" />

### Python
```python
# текст комментария
```

## Многострочный комментарий {#long_comment}

Блок **многострочный комментарий** позволяет ввести сразу несколько строк комментария.  
Каждая строка автоматически помечается как комментарий, а пустые строки сохраняются.

<BlockImage module="common/others" id="long_comment" />

### Python
```python
"""
первая строка
вторая строка

четвёртая строка
"""
```

## Ссылка {#link}

Блок **ссылка** позволяет добавить в **комментарии** **ссылку на страницу**, которую вы хотите открыть.  
По нажатию кнопки **открыть** вы переходите на страницу по указанному адресу.

<BlockImage module="common/others" id="link" />

### Python
```python
# https://example.com
```

## Выход {#exit}

Блок **выход** немедленно прерывает выполнение кода в программе.  
Он удобен, когда нужно принудительно завершить работу при определённом условии.

<BlockImage module="common/others" id="exit" />

### Python
```python
Utils.exit()
```
