# Функции

**Функция** — это **набор команд (блоков)**, выполняющих определённую задачу.  
Если объединить повторяющиеся действия в одну функцию, код станет **компактным и удобным в сопровождении**.

Функции обладают следующими свойствами.  
- **Многократное использование**: один раз описанную функцию можно вызывать сколько угодно раз.  
- **Вход и выход**: функция может принять параметры (входные значения), обработать их и вернуть результат (выходное значение).  
- **Улучшение читаемости кода**: позволяет логично выстроить ход программы.


## setup {#setup}

**Функция setup** вызывается только один раз — в момент запуска кода.  
В функции setup обычно пишут код, который задаёт начальные значения переменных или настраивает режим и параметры робота.  
Например, при управлении роботом на колёсах в функции setup можно задать начальную скорость колёс.  

<BlockImage module="common/functions" id="setup" />
  
С помощью функции `Utils.wait(...)` можно писать код, который выполняется по порядку во времени. В связке с **функцией loop**, работающей параллельно, это даёт не только простое последовательное выполнение, но и по-настоящему мощное программирование роботов.  

### Python
```python
def setup():
    # ...
    return
```

## loop {#loop}

**Функция loop** вызывается многократно, каждые 10 мс, всё время работы программы.  
В функции loop обычно пишут код, который циклически задаёт значения переменных или обнаруживает и обрабатывает события робота.

<BlockImage module="common/functions" id="loop" />

### Python
```python
def loop():
    # ...
    return
```

## Определение функции {#procedures_defnoreturn}

С помощью блока определения функции можно создать **новую функцию**.  
Функция без возвращаемого значения выполняет определённые действия, но **не возвращает никакого значения**.

<BlockImage module="common/functions" id="procedures_defnoreturn" />

### Python
```python
def myFunction(arg1, arg2):
    # ...
```

## Определение функции с возвращаемым значением {#procedures_defreturn}

Функция с возвращаемым значением выполняет определённую задачу, а затем **возвращает результат**, который можно использовать в других блоках.  

<BlockImage module="common/functions" id="procedures_defreturn" />

Функция ниже **принимает параметры x и y и возвращает результат x + y**.  

### Python
```python
def myFunction(x, y):
    return x + y
```

## Вызов функции {#procedures_callnoreturn}

После определения функции автоматически создаётся **блок пользовательской функции**.  
С его помощью можно вызвать и выполнить **заранее определённую функцию**.

<BlockImage module="common/functions" id="procedures_callnoreturn" />

### Python
```python
myFunction(arg1, arg2)
```

## Если вернуть {#procedures_ifreturn}

Это блок, который **сразу возвращает значение и завершает функцию**, когда внутри неё выполняется определённое условие.  
Использовать этот блок можно **только внутри функции**; в других местах он неактивен.

<BlockImage module="common/functions" id="procedures_ifreturn" />

### Python
```python
if condition:
    return value
```
