# Логика

Логические блоки обычно используются для управления блоками **условного оператора** и [**циклов**](Loops).

## Условный оператор (если ~ то) {#controls_if}

С помощью блока условного оператора задаются **условие** и **действие**, выполняемое при его соблюдении.

<BlockImage module="common/logic" id="controls_if" />

Например, можно написать такой код.  
Если значение переменной **x** больше 100, условие принимает значение **истина** и выводится текст «Большое число.».  
Если значение **x** не больше 100, условие принимает значение **ложь** и выводится «Не очень большое число.».

### Python
```python
if condition:
  # ...
elif condition2:
  # ...
else:
  # ...
```

## Сравнения {#logic_compare}

Есть шесть операторов сравнения.  
Каждый из них принимает два входных значения (обычно числа) и возвращает истину или ложь в зависимости от того, как эти значения соотносятся друг с другом.

<BlockImage module="common/logic" id="logic_compare" />

### Python
```python
A == B
A != B
A < B
A <= B
A > B
A >= B
```

## Логические операции {#logic_operation}

Блок **и** возвращает истину только тогда, когда оба входных значения истинны.  
Блок **или** возвращает истину, если истинно хотя бы одно из входных значений.  

<BlockImage module="common/logic" id="logic_operation" />

### Python
```python
A and B
A or B
```

## Не {#logic_negate}

Блок **не** меняет логическое значение на противоположное.  

<BlockImage module="common/logic" id="logic_negate" />

### Python
```python
not A
```

## Логическое значение {#logic_boolean}

Логическое значение можно получить с помощью одного блока с выпадающим списком, в котором выбирается **истина** или **ложь**.  

<BlockImage module="common/logic" id="logic_boolean" />

### Python
```python
True
False
```

## Тернарная операция {#logic_ternary}

Тернарный блок работает как простой условный оператор.  
Он принимает три входных значения.  
Первое — проверяемое логическое условие, второе — значение, возвращаемое, когда условие имеет значение **истина**.  
Третье — значение, возвращаемое, когда условие имеет значение **ложь**.  

<BlockImage module="common/logic" id="logic_ternary" />

### Python
```python
thenValue if test else elseValue
```
