# Управление

В блочном программировании **управляющие блоки** влияют на ход программы.  
Они позволяют выждать время, обнаружить нажатие клавиши или записать что-то в журнал.


## Ждать {#wait_sec}

Ждёт указанное время (в секундах), а затем выполняет следующую команду.

<BlockImage module="common/control" id="wait_sec" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| sec | Ввод (поле) | Время ожидания — **число, записанное напрямую** (например, `Utils.wait(0.5)`) | Вещественное число 0 или больше | - |
| sec | Ввод (блок) | Время ожидания — **переменная или выражение** (например, `Utils.wait(time)`) | Вещественное число 0 или больше | - |

### Python
```python
# поле sec = 2 → без изменений (в секундах)
Utils.wait(2)

# значение из переменной
Utils.wait(myVar)
```

## Ждать один кадр {#wait_1msec}

Приостанавливает выполнение программы на один кадр (около 0,001 секунды).

<BlockImage module="common/control" id="wait_1msec" />

### Параметры

(нет — фиксированные 0,001 секунды)

### Python
```python
Utils.wait(0.001)
```

## Нажатие клавиши {#key_pressed}

Возвращает **истину (True) или ложь (False)** в зависимости от того, нажата ли указанная клавиша.

<BlockImage module="common/control" id="key_pressed" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| key | Ввод | Название клавиши | space, up, left, right, down, a~z, 0~9,<br>shift, ctrl, alt, enter, tab, esc, backspace | - |

### Python
```python
Utils.keypressed('space')
```

## Записать в журнал {#log}

Выводит в окно **Консоль** текущее значение выбранной переменной или свойства.

<BlockImage module="common/control" id="log" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| data | Ввод | Выводимое значение | Любое значение | - |
| tag | Ввод | Тег записи | Строка | - |
| unit | Ввод | Отображаемая единица | Строка | - |

### Python
```python
Utils.log(data, '', '')
```

## Показать на графике {#scope}

Показывает изменения выбранного значения в окне **График** в виде графика в реальном времени.  
Можно задать цвет графика, а также его минимальное и максимальное значения, то есть диапазон.

<BlockImage module="common/control" id="scope" />

### Параметры

| Название | Вид | Описание | Диапазон / Тип | По умолчанию |
| --- | --- | --- | --- | --- |
| signal | Ввод (блок) | Значение сигнала на графике | Вещественное число | - |
| name | Ввод | Название графика | Строка | - |
| min_val | Ввод (поле) | Минимальное значение графика | Вещественное число | - |
| max_val | Ввод (поле) | Максимальное значение графика | Вещественное число | - |
| color | Цвет | Цвет графика (hex) | Строка hex | - |

### Python
```python
Utils.scope(signal, '', 0, 100, '#000000')
```
