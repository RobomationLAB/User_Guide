# Руководство пользователя RobomationLAB

**RobomationLAB** — это платформа, подготовленная для обучения ИИ, робототехнике и программированию,  
дающая интегрированную среду разработки в браузере Chrome для обучения программированию роботов в начальной и средней школе.

Этот документ подробно описывает, как пользоваться всеми блоками и кодом Python, доступными в программе.

Выберите нужный раздел справки на **боковой панели слева**.  
Посмотрите сразу то, о чём хотите узнать.
