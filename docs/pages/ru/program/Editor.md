# Редактор

**Редактор** — это область, где вы пишете код для управления роботом с помощью **блоков** или **скриптового кода**.  
Ниже описано, как программировать в **блочном** и **скриптовом (Python)** программировании и на что обращать внимание.

### Основная структура блоков {#block-structure}

Программируя в редакторе блочного кода, нужно придерживаться приведённой ниже основной структуры.

<BlockImage module="program/Editor" id="block-structure" /><br>

Редактор блочного кода разбирает и выполняет код, находящийся внутри блоков функций **функция setup** и **функция loop**.  
Поэтому код нужно писать, вставляя блоки внутрь блоков функций **функция setup** и **функция loop**.  

**функция setup**  
Внутри блока функции setup вы описываете действия, выполняемые в начале, при запуске кода.  
Блоком **ждать** можно добиться, чтобы действия выполнялись по порядку во времени.  

**функция loop**  
Внутри блока функции loop вы описываете действия, повторяющиеся всё время работы кода.  
Описанные действия повторяются каждые 10 мс.  

**⚙️ Примечание**  
(не считая собственных функций, созданных в **категории Функции**)  
Блоки, находящиеся вне блоков функций **функция setup** и **функция loop**, никак не влияют на выполнение кода.  

<br>

### Как пользоваться блоками {#block-usage}

**Добавление блока**  

<BlockImage module="program/Editor" id="block-add-1" row />
<BlockImage module="program/Editor" id="block-add-2" row />

<br>

Блок добавляется **перетаскиванием из палитры блоков** и **отпусканием в редакторе**.   
<br>

**Копирование и вставка блоков**  

Блок в редакторе копируется и вставляется двумя способами.  

1. Выделив блок, нажмите **Ctrl+C**, чтобы **скопировать** его.  
Нажатие **Ctrl+V** **вставляет** в редактор последний скопированный блок.  

2. Выделив блок, нажмите в меню **Правка** кнопку **«Копировать Ctrl+C»**, чтобы **скопировать** блок.  
Нажатие в меню **Правка** кнопки **«Вставить Ctrl+V»** **вставляет** в редактор последний скопированный блок.

<br>

**Удаление блока**  

Блок в редакторе удаляется тремя способами.

1. Выделив блок, нажмите клавишу **Backspace**, чтобы удалить его.<br>  

2. Блок также удаляется **перетаскиванием в редакторе** и **отпусканием на категории блоков**.  
<br>
<BlockImage module="program/Editor" id="block-delete-1" row />
<BlockImage module="program/Editor" id="block-delete-2" row />
<BlockImage module="program/Editor" id="block-delete-3" row />
<br>

3. Блок также удаляется **перетаскиванием в редакторе** и **отпусканием на корзине**.  
Удалённый блок вы найдёте в **корзине**.<br>  
<BlockImage module="program/Editor" id="block-trash" /><br>  

<br>

**Выделение нескольких блоков сразу**  

Несколько блоков в редакторе выделяются сразу двумя способами.

1. Удерживая клавишу **Shift**, протяните по рабочей области или щёлкайте по блокам по одному,  
и вы выделите несколько блоков сразу.  

2. **Кнопкой выделения** в правом нижнем углу рабочей области вы включите и выключите режим «выделение нескольких блоков».  
Залитая цветом кнопка означает, что режим включён.  
Незалитая кнопка означает, что режим выключен.  
<br>
<BlockImage module="program/Editor" id="block-mode-on" row />
<BlockImage module="program/Editor" id="block-mode-off" row />
<br>

Пока режим «выделение нескольких блоков» включён, можно только выделять блоки.   
Чтобы переместить или изменить несколько выделенных блоков сразу, после выделения нужно выключить этот режим.  

<br>

**Дополнительные возможности**

Кроме того, по **щелчку правой кнопкой мыши по блоку**  
вы увидите разные дополнительные пункты: **свернуть и развернуть блок, включить и выключить, справка** и другие.

### Основная структура кода {#python-structure}

Программируя в редакторе кода, нужно придерживаться приведённой ниже основной структуры.

```python
from robomation import *

# (если используете робота, объявите его как экземпляр, пример)
hamster_s = HamsterS(0)

# поместите сюда код настройки, выполняемый один раз:
def setup():
    pass

# поместите сюда управляющий код, выполняемый циклически:
def loop():
    pass
```

Редактор кода разбирает и выполняет код, находящийся внутри функций **setup** и **loop**.  
Поэтому код нужно писать внутри функций **setup** и **loop**.  
Кроме того, чтобы управлять роботом, в самом верху кода нужно разместить `from robomation import *` и объявить используемого робота как экземпляр.

**setup**  

Внутри функции setup вы описываете действия, выполняемые в начале, при запуске кода.  
Функцией **Utils.wait** можно добиться, чтобы действия выполнялись по порядку во времени.  

**loop**  
Внутри функции loop вы описываете действия, повторяющиеся всё время работы кода.  
Описанные действия повторяются каждые 10 мс.  


<br>

### Как пользоваться палитрой кода {#python-codes-usage}

Ниже на простых примерах описано, **как пользоваться палитрой кода при программировании**.  

### Поиск кода {#python-codes-find}

Палитра кода содержит множество функций и фрагментов кода, нужных при программировании робота.  

<BlockImage module="program/Editor" id="codes-find-1" /><br>

Среди пунктов категории **Код** вы найдёте такие, рядом с которыми стоит значок <BlockImage module="program/Editor" id="arrow-right" ext="svg" inline />.  

После одного щелчка по пункту **Логика** значок меняется на <BlockImage module="program/Editor" id="arrow-down" ext="svg" inline />, а **вложенные пункты** раскрываются и становятся видны.  
Пункт с вложенными пунктами мы называем «**категорией**».  

Если рядом с пунктом нет значка <BlockImage module="program/Editor" id="arrow-right" ext="svg" inline /> — как у **тернарной операции** в категории **Логика** — это значит, что **вложенных пунктов в нём нет**.  
Пункт без вложенных пунктов мы называем «**кодом**».  

<BlockImage module="program/Editor" id="codes-find-2" /><br>

Повторный щелчок по раскрытой категории меняет значок обратно на <BlockImage module="program/Editor" id="arrow-right" ext="svg" inline /> и скрывает вложенные пункты.  

Идя так по категориям, вы найдёте в палитре кода нужный фрагмент кода.

<br>

### Вставка кода в редактор {#python-codes-insert}

Код в редактор вставляется так.  

<BlockImage module="program/Editor" id="codes-insert-1" /><br>

Значок <BlockImage module="program/Editor" id="circle-empty" ext="svg" inline /> слева от названия пункта означает пункт без **параметров кода** на выбор.  
Это чаще всего пункты **категорий**, то есть те, у которых есть вложенные пункты.

Значок <BlockImage module="program/Editor" id="circle-fill" ext="svg" inline /> слева от названия пункта означает пункт, в котором можно выбрать **параметры кода**.  
Это чаще всего пункты **кода**, то есть те, у которых нет вложенных пунктов.

По **щелчку правой кнопкой мыши** по коду, который вы хотите вставить в редактор, вы увидите доступные пункты.  

<BlockImage module="program/Editor" id="codes-insert-menu" /><br>

По щелчку правой кнопкой мыши по пункту **кода** вы увидите одни и те же пункты, независимо от того, основная это функция или код, предназначенный для робота либо модуля расширения.

- **Вставить код**: вставляет выбранный код в место курсора в редакторе.
- **Справка**: открывает описание работы с этим кодом.
- **Отмена**: закрывает меню.

Для кода, предназначенного для робота или модуля расширения, выбор пункта **Вставить код** вставляет вызов метода на экземпляре этого робота.  
( например, `set_wheel_speed` робота HamsterS → `hamster_s.set_wheel_speed('both', 50)` )

<br>

**⚙️ Примечание**  

<BlockImage module="program/Editor" id="codes-remove-robot" /><br>

можно убрать из палитры кода через **щелчок правой кнопкой мыши → Удалить**.
