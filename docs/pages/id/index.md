# Panduan penggunaan RobomationLAB

**RobomationLAB** adalah platform yang dirancang khusus untuk pendidikan perangkat lunak AI dan robotika,  
menyediakan lingkungan penulisan terpadu berbasis peramban web Chrome untuk pendidikan pemrograman robot bagi siswa SD dan SMP.

Dokumen ini menjelaskan secara terperinci cara memakai semua blok dan kode Python yang disediakan program.

Anda dapat memilih topik bantuan yang diinginkan di **bilah sisi sebelah kiri**.  
Lihat sekarang hal yang sedang Anda cari tahu.
