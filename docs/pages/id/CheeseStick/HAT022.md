# HAT-022 Piano Sentuh

## Deklarasi instans {#instance}

Saat Anda menambahkan blok HAT-022 Piano Sentuh(HAT022) ke area kerja, deklarasi instans berikut otomatis disisipkan ke kode Python:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parameter

| Nama | Jenis | Keterangan | Rentang / Tipe | Bawaan |
| --- | --- | --- | --- | --- |
| index | Pilihan daftar turun | Nomor instans (mulai dari 0) | bilangan bulat 0 atau lebih | 0 |


## Memulai piano sentuh {#start}

Membuat piano sentuh dapat dipakai.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parameter

(tidak ada)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Nilai masukan tuts {#key_input}

Keadaan masukan tuts yang dipilih  
Mengembalikan 1 bila tuts sedang ditekan dan 0 bila tuts tidak ditekan.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parameter

| Nama | Jenis | Keterangan | Rentang / Tipe | Bawaan |
| --- | --- | --- | --- | --- |
| unit | Pilihan daftar turun | Tuts nada | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
