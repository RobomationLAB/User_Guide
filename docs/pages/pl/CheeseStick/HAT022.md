# HAT-022 Pianino dotykowe

## Deklaracja instancji {#instance}

Po dodaniu bloku HAT-022 Pianino dotykowe(HAT022) do obszaru roboczego w kodzie Python automatycznie pojawia się następująca deklaracja instancji:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parametry

| Nazwa | Rodzaj | Opis | Zakres / Typ | Domyślnie |
| --- | --- | --- | --- | --- |
| index | Opcja listy rozwijanej | Numer instancji (licząc od 0) | Liczba całkowita 0 lub większa | 0 |


## Uruchom pianino dotykowe {#start}

Włącza pianino dotykowe.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parametry

(brak)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Wejście klawisza {#key_input}

Stan wejścia wybranego klawisza  
Zwraca 1, gdy klawisz jest wciśnięty, a 0, gdy nie jest.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parametry

| Nazwa | Rodzaj | Opis | Zakres / Typ | Domyślnie |
| --- | --- | --- | --- | --- |
| unit | Opcja listy rozwijanej | Klawisz nuty | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
