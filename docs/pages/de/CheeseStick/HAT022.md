# HAT-022 Touch-Piano

## Instanz deklarieren {#instance}

Wenn du einen HAT-022 Touch-Piano(HAT022)-Block zum Arbeitsbereich hinzufügst, wird im Python-Code automatisch die folgende Instanzdeklaration eingefügt:

```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()
```

### Parameter

| Name | Art | Beschreibung | Bereich / Typ | Standardwert |
| --- | --- | --- | --- | --- |
| index | Dropdown-Option | Instanznummer (beginnt bei 0) | ganze Zahl ≥ 0 | 0 |


## Touch-Piano starten {#start}

Verwendet das Touch-Piano.

<BlockImage module="CheeseStick/HAT022" id="start" />

### Parameter

(keine)

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.start()
```

## Tasteneingang {#key_input}

Der Eingabezustand der gewählten Klaviertaste  
Ist die Taste gedrückt, wird 1 ausgegeben, ist sie nicht gedrückt, 0.

<BlockImage module="CheeseStick/HAT022" id="key_input" />

### Parameter

| Name | Art | Beschreibung | Bereich / Typ | Standardwert |
| --- | --- | --- | --- | --- |
| unit | Dropdown-Option | Taste der Tonleiter | Do(C), Do#(C#), Re(D), Re#(D#), Mi(E), Fa(F), Fa#(F#), Sol(G), Sol#(G#), La(A), La#(A#), Si(B), ◀(left), ▶(right), fn(fn) | - |

### Python
```python
cheesestick = CheeseStick(0)
hat022 = cheesestick.HAT022()

hat022.key_input('C')
```
