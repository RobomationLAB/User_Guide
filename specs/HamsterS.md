# 햄스터 S 하드웨어 사양

햄스터 S(HamsterS)는 **마이크로 스텝 모터로 구동하는 소형 바퀴 로봇**입니다.  
**엔코더가 있어 거리와 각도를 지정해 움직일 수 있습니다.**

<br>

## 0. 문서 정보

| 항목 | 내용 |
|---|---|
| 제품명 | 햄스터 S (Hamster-S) |
| 분류 | 2륜 구동 바퀴 로봇 |
| 원본 자료 | 햄스터 S 기술문서 |
| 이 문서가 다루지 않는 것 | BLE 패킷, 센서·모터 패킷 구조, 자율 모드 |

## 5. 확장 포트와 부속품

### 5.1 확장 포트 (P1 · P2)

본체에는 **P1 · P2 두 개의 외부 입출력 단자**가 있습니다. 코드에서는 `A` · `B` 로 부릅니다.  

| ID | 모드 | 범위 | 포트 | 비고 |
|---|---|---|---|---|
| `HAMSTER_S.PORT.ADC` | 아날로그 입력 | 0 ~ 255 | A · B | 전원 전압(약 3.7V) 또는 3.6V 기준 |
| `HAMSTER_S.PORT.DI` | 디지털 입력 | 0 / 1 | A · B | 풀업 · 풀다운 선택 가능. 기본은 풀업 |
| `HAMSTER_S.PORT.SERVO` | 서보 출력 | 1 ~ 180° | A · B | **1° = 0.5ms, 90° = 1.5ms, 180° = 2.5ms** |
| `HAMSTER_S.PORT.PWM` | PWM 출력 | 0 ~ 255 | A · B | 주기 20ms |
| `HAMSTER_S.PORT.DO` | 디지털 출력 | 0 / 1 | A · B | |
| `HAMSTER_S.PORT.NEOPIXEL` | NeoPixel | 최대 **36개** | **A 포트만** | RGB / RGBW. 밝기 0 ~ 255 |
| `HAMSTER_S.PORT.UART` | 시리얼 통신 | 18바이트 이하 | A(송신) · B(수신) | 9,600 ~ 115,200 bps. **9600bps 가 가장 안정적** |

| ID | 항목 | 값 | 비고 |
|---|---|---|---|
| `HAMSTER_S.PORT.PULL` | 내부 풀업 · 풀다운 저항 | 약 10 kΩ | |
| `HAMSTER_S.PORT.COUNT` | 포트 수 | 2 | **포트당 한 번에 한 가지 방식만** 가능 |
| `HAMSTER_S.PORT.AUX_POWER` | 보조 전원 단자 | 5핀 | |
| `HAMSTER_S.PORT.USB` | 충전 단자 | Micro-USB 5핀 | |

> **서보 펄스 폭은 1° = 0.5ms, 90° = 1.5ms, 180° = 2.5ms 입니다.**  
> 다른 제품의 서보 설정값을 그대로 가져오면 각도가 어긋납니다.

### 5.2 부속품

부속품은 **로봇에 장착한 채로 A 또는 B 포트에 연결**해 사용합니다.  
둘 다 서보로 동작하므로, 연결한 포트는 **서보 출력 모드**로 설정됩니다.

| ID | 부속품 | 구동 방식 | 동작 |
|---|---|---|---|
| `HAMSTER_S.ACC.GRIPPER` | 그리퍼 | 서보 **켜기 / 끄기** | 열기 / 닫기 |
| `HAMSTER_S.ACC.SHOOTER` | 슈터 | 서보 **각도 제어** | 지정한 각도로 발사 |

> **부속품 하나가 포트 하나를 차지합니다.** 포트는 A · B 두 개뿐이므로,  
> 그리퍼와 슈터를 함께 사용하면 **다른 센서나 NeoPixel 을 붙일 포트가 남지 않습니다.**

파지력 · 벌어짐 폭 · 발사 거리는 모두 `미공개` 입니다.

## 8. 코드 생성 규칙

### R1. 격자 이동은 인쇄된 맵이 있어야 한다 (MUST)

**판정** — 햄스터 S 의 격자 이동은 거리를 세는 것이 아니라  
**바닥 센서로 검은 선과 교차점을 찾아** 동작합니다.

**조치** — **검은 선이 인쇄된 격자 맵 위에서만 동작**한다는 점을 반드시 안내합니다.  
맵이 없으면 로봇이 멈추지 않고 계속 전진합니다.  
맵 없이 일정 거리를 가야 한다면 **거리 지정 이동**을 사용하도록 코드를 바꿉니다.

### R2. 근접 센서를 거리 값으로 사용하지 않는다 (MUST NOT)

근접 센서는 **0 ~ 255 의 상대값**이며 cm 단위가 아닙니다.  
감지 가능한 범위는 **10cm 이내**입니다.

### R3. 정밀 반복 작업에는 배터리를 확인한다 (MUST)

**3.25V 아래에서는 바퀴 구동이 부정확해집니다.**  
같은 경로를 여러 번 도는 코드나 도형을 그리는 코드를 만들 때는  
배터리 확인 코드를 함께 제시합니다.

### R4. 가속도 대역폭을 지정하지 않는다 (MUST NOT)

**BMA253 과 BMA456 두 부품이 혼용되며 설정값의 의미가 다릅니다.**  
어느 것이 들어 있는지 알 수 없으므로 대역폭을 지정하는 코드를 만들지 않습니다.

### R5. 서보 펄스 폭은 0.5 / 1.5 / 2.5ms 다 (MUST)

1° = 0.5ms, 90° = 1.5ms, 180° = 2.5ms 입니다.  
**다른 제품의 서보 설정값을 가져와 사용하지 않습니다.** 각도 지정 범위가 같아도 실제 회전량이 달라집니다.

### R6. NeoPixel 은 A 포트에만 (MUST)

**B 포트에는 연결할 수 없습니다.** 최대 36개입니다.

### R7. 두 바퀴 이동은 먼저 끝난 쪽을 기준으로 멈춘다 (참고)

거리를 지정해 양 바퀴를 서로 다른 속도로 움직이면,  
**먼저 목표에 도달한 바퀴에 맞춰 양쪽이 동시에 정지**합니다.  
곡선 주행은 직접 계산하지 말고 라이브러리의 전용 기능을 사용하도록 코드를 만듭니다.

### R8. 바닥 조건을 전제한다 (참고)

이동 정확도와 바닥 센서 값은 **A4 복사용지 정도의 평평한 실내 바닥**을 기준으로 합니다.  
바닥 센서의 `흰색 = 100` 기준도 A4 용지입니다.

## 9. 미공개 · 충돌 항목

### 9.1 미공개 — 추정 금지

아래 값은 **공개되지 않았습니다.**
추정하거나 임의의 숫자로 채우지 않고, 값이 없다는 사실을 그대로 알립니다.
이 값에 의존하는 코드도 만들지 않습니다.

다만 **이동 시간 · 회전 시간처럼 로봇을 돌려 보면 눈으로 바로 확인되는 값**은 예외입니다.
어림값을 출발점으로 제시하되, **사양이 아니라 추정치임을 밝히고** 직접 맞춰 보도록 안내합니다.

| 분류 | 항목 |
|---|---|
| 구동 | 최대 펄스 속도(PPS), 모터 토크, 정지 전류 |
| 구동 | 최소 회전 반경, 최대 적재 하중, 등판 각도 |
| 부속품 | 그리퍼 파지력 · 벌어짐 폭, 슈터 발사 거리 |
| 센서 | 장착된 가속도 부품(BMA253 / BMA456)을 구분하는 방법 |

### 9.2 충돌 — 채택값과 다른 표기

원본 자료에 따라 값이 다르게 적힌 항목입니다.
코드와 설명에는 **채택값만** 사용합니다.

| 항목 | 채택값 | 다른 표기 |
|---|---|---|
| 근접 감지 거리 | 10 cm | 사양표 최대 30cm / 본문 최대 15cm |
| LED 색상 수 | 풀컬러 (R · G · B 각 0~255) | 외형 도면에는 "7 colors" 로 표기됨 |
| 속도 지정 범위 | -100 ~ 100 | 패킷 정의 -128 ~ +127 |
| 온도 범위 | -40 ~ +87.5 °C | 외형 도면 -45 ~ +85°C |
| 동작 시간 | 약 45분 | 외형 도면 최소 1시간 |
