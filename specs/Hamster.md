# 햄스터 하드웨어 사양

햄스터(Hamster)는 **DC 모터로 구동하는 소형 바퀴 로봇**입니다.  
근접·바닥·조도·가속도 센서를 갖추고 있으며, 확장 포트로 서보나 LED 를 붙일 수 있습니다.

**햄스터는 엔코더가 없어 이동 거리를 알 수 없습니다.**  
거리를 지정해 움직이는 기능이 제공되지 않으므로, 이동은 **시간**으로 제어합니다. (6장 R1)

<br>

## 0. 문서 정보

| 항목 | 내용 |
|---|---|
| 제품명 | 햄스터 (Hamster) |
| 분류 | 2륜 구동 바퀴 로봇 |
| 원본 자료 | 햄스터 기술문서 (Version 4.3) |
| 이 문서가 다루지 않는 것 | BLE 패킷, 센서·모터 패킷 구조, 자율 모드, USB 동글 |

## 2. 구동계

햄스터의 구동부입니다.
**엔코더가 없어 이동한 거리를 알 수 없으므로**, 이동은 거리가 아니라 **시간**으로 제어합니다.

| ID | 항목 | 값 | 단위 | 근거 / 비고 |
|---|---|---|---|---|
| `HAMSTER.DRIVE.MOTOR` | 모터 | DC 기어드 모터 × 2 | | 위성(유성) 기어 감속기 |
| `HAMSTER.DRIVE.TIRE` | 타이어 | NB O-ring 고무 | | |
| `HAMSTER.DRIVE.SPEED_RANGE` | 속도 지정 범위 | -100 ~ 100 | % | 100단계. 음수는 후진 |
| `HAMSTER.DRIVE.SPEED_MAX` | **최대 이동 속도** | **25** | cm/초 | 속도 100 기준 |
| `HAMSTER.DRIVE.ENCODER` | 엔코더 | **없음** | | **이동 거리를 알 수 없습니다** |
| `HAMSTER.DRIVE.GEAR_RATIO` | 기어비 | `미공개` | | |
| `HAMSTER.DRIVE.WHEEL_DIA` | 바퀴 지름 | `미공개` | | |
| `HAMSTER.DRIVE.TRACK` | 바퀴 축간거리 | `미공개` | | |

## 3. 센서

햄스터에 들어 있는 센서는 아래가 전부입니다.

| ID | 센서 | 위치 | 범위 | 단위 | 비고 |
|---|---|---|---|---|---|
| `HAMSTER.SENSOR.PROXIMITY` | 근접 센서 | 앞면 좌 · 우 2개 | 0 ~ 255 | | 가까울수록 값이 커집니다 |
| `HAMSTER.SENSOR.PROXIMITY.RANGE` | 근접 감지 거리 | | **0 ~ 10** | cm | 1mm 정밀도. `충돌` 사양표에는 최대 30cm |
| `HAMSTER.SENSOR.FLOOR` | 바닥 센서 | 바닥 좌 · 우 2개 | 0 ~ 100 | | 흰색(A4 용지) = 100. `충돌` 도면에는 0~255 |
| `HAMSTER.SENSOR.LIGHT` | 조도 센서 | 앞면 | 0 ~ 65,000 | Lux | |
| `HAMSTER.SENSOR.ACC` | 가속도 센서 | 내부 | ±2 / ±4 / ±8 / ±16 | G | 기본 ±2G. `충돌` 도면에는 ±2G 고정 |
| `HAMSTER.SENSOR.TEMP` | 온도 센서 | 내부 | -40 ~ +87.5 | °C | 0.5°C 단위. **기판 내부 온도** |
| `HAMSTER.SENSOR.RSSI` | 신호 세기 | | -93 까지 | dBm | 신뢰 구간 -50 ~ -80 |

> **근접 센서는 햇빛 아래에서도 동작**하지만, 감지 거리는 **10cm 이내**입니다.  
> 사양표의 30cm 는 부품 사양이며 실제 사용 범위가 아닙니다.

## 4. 출력

### 4.1 제어 가능

코드로 제어할 수 있는 햄스터의 출력 장치는 아래가 전부입니다.

| ID | 항목 | 값 | 비고 |
|---|---|---|---|
| `HAMSTER.OUT.LED` | LED | 좌 · 우 **2개** | **7색 + 꺼짐.** 검정 · 빨강 · 노랑 · 초록 · 하늘 · 파랑 · 자주 · 하양 |
| `HAMSTER.OUT.BUZZER` | 부저 주파수 | 1.0 ~ 167,772.15 Hz | **소프트웨어 상으로는 최대 6553.5 Hz 까지만 허용합니다** |
| `HAMSTER.OUT.NOTE` | 음정 | 88건반, A0 ~ C8 | |

**LED 는 8단계 색상만 지원합니다.** 밝기나 중간색을 지정할 수 없습니다.

### 4.2 상태 표시등 — 제어 불가

아래 표시등은 펌웨어가 직접 켜고 끕니다. **코드로 제어할 수 없습니다.**

| 표시등 | 색 | 표시 내용 |
|---|---|---|
| 블루투스 연결 등 | 청색 | 연결되면 켜집니다 |
| USB 충전 등 | 적색 | 만충되면 꺼집니다 |

## 5. 확장 포트와 부속품

### 5.1 확장 포트 (P1 · P2)

본체에는 **P1 · P2 두 개의 외부 입출력 단자**가 있습니다. 코드에서는 `A` · `B` 로 부릅니다.

확장 포트에 센서나 서보를 붙일 때 쓸 수 있는 모드입니다.

| ID | 모드 | 범위 | 비고 |
|---|---|---|---|
| `HAMSTER.PORT.ADC` | 아날로그 입력 | 0 ~ 255 | 0 ~ 3.3V |
| `HAMSTER.PORT.DI` | 디지털 입력 | 0 / 1 | 전원 전압의 1/2(약 1.8V) 이상이면 1 |
| `HAMSTER.PORT.SERVO` | 서보 출력 | 1 ~ 180° | 0 = 정지. 1° = 1.0ms, 90° = 1.5ms, 180° = 2.0ms |
| `HAMSTER.PORT.PWM` | PWM 출력 | 0 ~ 255 | 주기 20ms |
| `HAMSTER.PORT.DO` | 디지털 출력 | 0 / 1 | |

| ID | 항목 | 값 | 비고 |
|---|---|---|---|
| `HAMSTER.PORT.PULL` | 내부 풀업 · 풀다운 저항 | 약 10 kΩ | 기본은 풀업 |
| `HAMSTER.PORT.COUNT` | 포트 수 | 2 | **포트당 한 번에 한 가지 방식만** 가능 (동작 중 변경 가능) |
| `HAMSTER.PORT.AUX_POWER` | 보조 전원 단자 | 2핀 | 3.7V 리튬 폴리머 전지 출력. 외부 전원 입력도 가능 |
| `HAMSTER.PORT.USB` | 충전 단자 | Micro-USB 5핀 | |

### 5.2 부속품

부속품은 **로봇에 장착한 채로 A 또는 B 포트에 연결**해 사용합니다.  
둘 다 서보로 동작하므로, 연결한 포트는 **서보 출력 모드**로 설정됩니다.

| ID | 부속품 | 구동 방식 | 동작 |
|---|---|---|---|
| `HAMSTER.ACC.GRIPPER` | 그리퍼 | 서보 **켜기 / 끄기** | 열기 / 닫기 |
| `HAMSTER.ACC.SHOOTER` | 슈터 | 서보 **각도 제어** | 지정한 각도로 발사 |

> **부속품 하나가 포트 하나를 차지합니다.** 포트는 A · B 두 개뿐이므로,  
> 그리퍼와 슈터를 함께 사용하면 **다른 센서를 붙일 포트가 남지 않습니다.**

파지력 · 벌어짐 폭 · 발사 거리는 모두 `미공개` 입니다.

## 6. 라인 트레이싱 조건

바닥의 검은 선을 따라가는 기능을 사용할 때의 **인쇄 조건**입니다.

라인을 따라가는 코드가 제대로 동작하려면 인쇄물이 아래 조건을 만족해야 합니다.

| ID | 항목 | 값 | 단위 | 비고 |
|---|---|---|---|---|
| `HAMSTER.LINE.WIDTH` | 권장 라인 폭 | 9.0 | mm | 검정 · 흰색 모두 |
| `HAMSTER.LINE.WIDTH_MAX` | 최대 라인 폭 | 10 | mm | 90도로 꺾이는 모서리는 45도로 잘라 이 폭을 넘지 않게 합니다 |
| `HAMSTER.LINE.SENSOR_GAP` | 바닥 센서 간격 | 16 | mm | |
| `HAMSTER.LINE.SPEED` | 라인 주행 속도 | 0 ~ 7 | 단계 | 7 = 최대 속도 |

## 8. 코드 생성 규칙

### R1. 거리·각도 지정 이동 기능이 없다 (MUST NOT)

**조건** — "10cm 앞으로", "90도 회전" 처럼 거리나 각도로 이동을 요청받은 경우

**판정** — **햄스터에는 엔코더가 없어 이동량을 측정할 수 없습니다.**  
거리나 각도를 지정하는 기능 자체가 제공되지 않습니다.  
햄스터가 제공하는 이동 방식은 **속도 지정**과 **시간 지정** 두 가지입니다.

**조치** — 시간을 지정해 움직이는 기능으로 코드를 만들고,  
**이동 거리가 보장되지 않는다는 점**을 알립니다. 거리를 시간으로 환산해 제시하지 않습니다.

**안내 문구 예**  
> 햄스터는 이동 거리를 재는 장치가 없어 "10cm 이동" 을 수행할 수 없습니다.  
> 거리를 지정하는 기능이 제공되지 않아, 속도와 시간을 정해 움직이는 방식으로 작성했습니다.  
> 실제 이동 거리는 바닥 상태와 배터리 전압에 따라 달라집니다.

### R2. 격자 이동은 인쇄된 맵이 있어야 한다 (MUST)

**조건** — 격자 칸 단위로 이동하는 기능을 사용하는 코드

**판정** — 햄스터의 격자 이동은 **바닥 센서로 검은 선과 교차점을 찾아** 동작합니다.  
거리를 세어 움직이는 것이 아닙니다.

**조치** — **검은 선이 인쇄된 격자 맵 위에서만 동작**한다는 점을 반드시 안내합니다.  
맵이 없으면 로봇이 멈추지 않고 계속 전진합니다.

### R3. 근접 센서를 거리 값으로 사용하지 않는다 (MUST NOT)

근접 센서는 **0 ~ 255 의 상대값**이며 cm 단위가 아닙니다.  
값이 클수록 가깝다는 뜻일 뿐, 몇 cm 인지 알 수 없습니다.  
감지 가능한 범위는 **10cm 이내**입니다.

### R4. 온도 센서를 실내 온도로 사용하지 않는다 (MUST NOT)

기판 내부 온도입니다. 실내 온도나 물체 온도로 사용하는 코드를 만들지 않습니다.

### R5. LED 는 8가지 색만 (MUST)

밝기 조절이나 중간색 지정을 요청받으면 **불가능함을 알리고**,  
지원되는 8색 중에서 가장 가까운 색으로 대체합니다.

### R6. 저전압에서는 동작을 보장하지 않는다 (MUST)

**3.5V 아래에서는 통신과 연결은 정상이지만 모터가 제대로 돌지 않습니다.**  
연결이 되었다고 해서 정상 동작한다고 판단하면 안 됩니다.  
반복 주행이나 시간 기반 이동을 다루는 코드에는 배터리 확인 코드를 함께 제시합니다.

### R7. 바닥 조건을 전제한다 (참고)

이동 정확도와 바닥 센서 값은 **A4 복사용지 정도의 평평한 실내 바닥**을 기준으로 합니다.  
바닥 센서의 `흰색 = 100` 기준도 A4 용지입니다.

## 9. 미공개 · 충돌 항목

### 9.1 미공개 — 추정 금지

아래 값은 **공개되지 않았습니다.**
추정하거나 임의의 숫자로 채우지 않고, 값이 없다는 사실을 그대로 알립니다.
이 값에 의존하는 코드도 만들지 않습니다.

다만 **이동 시간 · 회전 시간처럼 로봇을 돌려 보면 눈으로 바로 확인되는 값**은 예외입니다.
어림값을 출발점으로 제시하되, **사양이 아니라 추정치임을 밝히고** 직접 맞춰 보도록 안내합니다.

| 분류 | 항목 |
|---|---|
| 구동 | 바퀴 지름, 축간거리, 기어비, 회전 반경 |
| 구동 | 회전 각도와 시간의 관계 |
| 부속품 | 그리퍼 파지력 · 벌어짐 폭, 슈터 발사 거리 |
| 성능 | 최대 적재 하중, 등판 각도 |

### 9.2 충돌 — 채택값과 다른 표기

원본 자료에 따라 값이 다르게 적힌 항목입니다.
코드와 설명에는 **채택값만** 사용합니다.

| 항목 | 채택값 | 다른 표기 |
|---|---|---|
| 근접 감지 거리 | 10 cm | 사양표 최대 30cm |
| 바닥 센서 범위 | 0 ~ 100 | 패킷 정의 0 ~ 255 |
| 온도 범위 | -40 ~ +87.5 °C | 외형 도면 -45 ~ +85°C |
| 충전 시간 | 30 분 | 외형 도면 약 25분 |
