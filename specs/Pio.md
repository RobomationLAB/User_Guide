# 삐오 하드웨어 사양

삐오(Pio)는 **병아리 모양의 바퀴 로봇**입니다.  
버튼만으로 코딩할 수 있고, 목을 좌우로 움직이며 눈 LED 로 표정을 냅니다.

**삐오에는 환경 센서가 하나도 없습니다.**  
거리·바닥·조도·색·가속도 센서가 전부 없으므로, 주변을 감지하는 코드를 만들 수 없습니다.

<br>

## 0. 문서 정보

| 항목 | 내용 |
|---|---|
| 제품명 | 삐오 (Pio) / Baby Chicken |
| 분류 | 2륜 구동 바퀴 로봇 |
| 원본 자료 | 삐오 기술문서 |
| 이 문서가 다루지 않는 것 | BLE 패킷, 튜터 모드, 데모 · 히든 모드 |

<br>

## 2. 구동계

바퀴 두 개와 **스테인리스 볼 캐스터** 하나로 지지합니다.

### 2.1 모터

| ID | 항목 | 값 | 단위 | 비고 |
|---|---|---|---|---|
| `PIO.DRIVE.MOTOR` | 바퀴 모터 | 마이크로 스텝 모터 × 2 | | 1/32 기어박스 |
| `PIO.DRIVE.NECK_MOTOR` | 목 모터 | 마이크로 스텝 모터 × 1 | | 1/32 감속 |
| `PIO.DRIVE.SPEED_RANGE` | 속도 지정 범위 | -100 ~ 100 | % | |
| `PIO.DRIVE.PPS_NORMAL` | 기본 모드 최대 속도 | 3,000 | PPS | |
| `PIO.DRIVE.PPS_TURBO` | **터보 모드 최대 속도** | 4,800 | PPS | |
| `PIO.DRIVE.PULSE_PER_CM` | 1cm 당 펄스 | 968 | 펄스 | `라이브러리 보정값` 원본 문서 미공개 |
| `PIO.DRIVE.PULSE_PER_DEG` | 1도 당 펄스 | 41.955 | 펄스 | `라이브러리 보정값` |
| `PIO.DRIVE.ODOMETRY` | 이동 거리 | 0 ~ 65,535 | 펄스 | 초과하면 0부터 다시 시작 |
| `PIO.DRIVE.WHEEL_DIA` | 바퀴 지름 | `미공개` | | |
| `PIO.DRIVE.TRACK` | 바퀴 축간거리 | `미공개` | | |

### 2.2 바퀴 오프셋 — 제자리 회전의 함정

| ID | 항목 | 값 | 단위 |
|---|---|---|---|
| `PIO.DRIVE.WHEEL_OFFSET` | 바퀴 축이 몸체 중심에서 벗어난 거리 | **14.5** | mm |

삐오는 바퀴 두 개와 **뒤쪽의 볼 캐스터**로 몸체를 지지합니다.  
그래서 **바퀴 축이 몸체 중심보다 14.5mm 앞쪽**에 있습니다.

회전은 언제나 바퀴 축을 중심으로 일어납니다.  
따라서 제자리에서 바로 돌면 몸체 중심이 바퀴 축을 반지름 14.5mm 로 돌게 되어,  
**회전을 마쳤을 때 몸체가 원래 칸의 중앙에서 벗어나 있습니다.**  
직진할 때는 이런 문제가 생기지 않습니다.

격자 이동 기능은 이를 보정하기 위해 **뒤로 14.5mm 물러난 뒤 90° 회전**하고 다시 전진합니다.  
직접 회전 코드를 만들 때도 같은 보정이 필요할 수 있습니다.

### 2.3 목 관절

| ID | 항목 | 값 | 단위 | 비고 |
|---|---|---|---|---|
| `PIO.NECK.ANGLE` | **물리적 가동 범위** | **-45 ~ +45** | 도 | 1도 단위 |
| `PIO.NECK.ANGLE_CMD` | 명령으로 넣을 수 있는 값 | -90 ~ +90 | 도 | **범위를 넘으면 모터 탈조가 발생합니다** |
| `PIO.NECK.SPEED` | 목 속도 | -6 ~ +6 | | `충돌` 패킷 표에는 -100 ~ 100 |

## 3. 센서

**읽을 수 있는 것은 아래 다섯 가지뿐입니다.**

삐오에는 거리 · 바닥 · 조도 · 색 · 가속도 같은 **환경 센서가 없습니다.**
아래는 로봇이 내부에서 세는 값이며, 주변을 감지하는 용도로 쓸 수 없습니다.

| ID | 항목 | 범위 | 비고 |
|---|---|---|---|
| `PIO.SENSOR.DISTANCE` | 이동 거리 | 0 ~ 65,535 펄스 | |
| `PIO.SENSOR.NECK` | 목 각도 | -45 ~ +45 도 | |
| `PIO.SENSOR.KEYPAD` | 버튼 | 8개 | 아래 5.1 참조 |
| `PIO.SENSOR.BATTERY` | 배터리 전압 | 2.0 ~ 4.55 V | |
| `PIO.SENSOR.RSSI` | 신호 세기 | -93 까지 dBm | |

**없는 센서** — 거리(근접) · 바닥(라인) · 조도 · 컬러 · 가속도 · 온도

<br>

## 4. 출력

### 4.1 제어 가능

코드로 제어할 수 있는 삐오의 출력 장치는 아래가 전부입니다.

| ID | 항목 | 값 | 비고 |
|---|---|---|---|
| `PIO.OUT.EYE` | 눈 LED | **2개** | 풀컬러. R · G · B 각 0 ~ 255 |
| `PIO.OUT.STATE_LED` | 상태 LED | **1개** | 풀컬러 |
| `PIO.OUT.PATTERN` | 눈 표시 패턴 | 초기화 · 깜빡임 · 디밍 · 무지개 | **두 눈이 함께 바뀝니다. 한쪽만 제어할 수 없습니다** |
| `PIO.OUT.BUZZER` | 부저 주파수 | 27.5 ~ 6,553.5 Hz | **27.5 Hz 미만은 스피커 보호를 위해 소리가 나지 않습니다** |
| `PIO.OUT.NOTE` | 음정 | 88건반, A0 ~ C8 | |
| `PIO.OUT.CLIP` | 내장 사운드 | 22종 | `충돌` 표에는 23종 |
| `PIO.OUT.MELODY` | 멜로디 | 24종 | `충돌` 표에는 27종 |

### 4.2 상태 표시등 — 제어 불가

충전 표시등은 코드로 제어할 수 없습니다. 충전 중 적색으로 켜지고 완충되면 꺼집니다.

<br>

## 5. 입력과 확장

### 5.1 버튼

**전원 버튼 1개 + 명령 입력 버튼 8개, 합계 9개**이며 윗면에 **3 × 3 으로 배치**되어 있습니다.

| | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| **위** | 반복 (Repeat) | **앞으로** (녹색 ↑) | 동작 (Action) |
| **가운데** | **왼쪽** (노란색 ↰) | **실행** (주황색 ▶) | **오른쪽** (파란색 ↱) |
| **아래** | **전원** | **뒤로** (빨간색 ↓) | 지우기 (Clear) |

| 버튼 | 기능 |
|---|---|
| 앞으로 · 뒤로 · 왼쪽 · 오른쪽 | 이동 코드 입력 |
| 실행 (Play) | 입력한 코드 실행 |
| 동작 (Action) | 동작 코드 입력 |
| 반복 (Repeat) | 반복 지정. 3회 반복하려면 2번 누릅니다 |
| 지우기 (Clear) | 입력 삭제 |

**전원 버튼은 왼쪽 아래**에 있습니다.  
(원본 문서 본문에는 "왼쪽 상단" 으로 적힌 곳이 있으나 키패드 배치와 맞지 않습니다.)

### 5.2 확장 포트

**삐오에는 확장 포트가 없습니다.**  
외부 단자는 USB-C 충전 단자와 리셋 스위치뿐입니다. 리셋을 누르면 전원이 꺼집니다.

<br>

## 6. 격자 이동

| ID | 항목 | 값 | 단위 | 비고 |
|---|---|---|---|---|
| `PIO.GRID.CELL` | 격자 한 칸 | **10 × 10** | cm | |
| `PIO.GRID.STEP` | 앞으로 한 칸 | 10 | cm | |
| `PIO.GRID.TURN` | 회전 | 90 | 도 | |
| `PIO.GRID.HEADING_TOL` | 시작 각도 허용 오차 | **5 이하** | 도 | 초과하면 위치 오차가 크게 누적됩니다 |

**격자 이동은 펄스로 계산합니다.** 인쇄된 맵이 없어도 동작합니다.

**바닥 조건** — 바퀴 마찰력을 고려해 **A4 용지를 기준 바닥재**로 합니다.  
**고무 바퀴가 마모되면 이동 거리와 회전 각도가 부정확해지므로 교환합니다.**

<br>

## 7. 전원과 배터리

전원 사양입니다. 동작 시간은 공개되지 않았습니다. (9.1 참조)

| ID | 항목 | 값 | 단위 | 비고 |
|---|---|---|---|---|
| `PIO.POWER.BATTERY` | 배터리 | Li-Poly 3.7V, 500 | mAh | |
| `PIO.POWER.RUNTIME` | 연속 동작 시간 | 약 45 | 분 | |
| `PIO.POWER.STANDBY` | 대기 시간 | 최대 12 | 시간 | |
| `PIO.POWER.CHARGE` | 완충 시간 | 2 ~ 3 | 시간 | USB-C |
| `PIO.POWER.FAIL` | 동작 정지 | 3.35 | V | |
| `PIO.POWER.OVER` | 과전압 경고 | | | 사이렌이 울립니다 |
| `PIO.POWER.AUTO_OFF` | 자동 전원 차단 | 30 | 분 | 버튼 입력이 없을 때. 원격 제어 중에는 적용되지 않습니다 |
| `PIO.POWER.FORCE_OFF` | 강제 종료 | 2 | 초 | 전원 버튼 길게 누름 |

과전류 방지 퓨즈가 내장되어 있습니다.

## 8. 코드 생성 규칙

### R1. 센서를 읽는 코드를 만들지 않는다 (MUST NOT)

**삐오에는 환경 센서가 하나도 없습니다.**  
"장애물을 피해라", "검은 선을 따라가라", "밝으면 멈춰라" 같은 요청은 수행할 수 없습니다.

**조치** — 기능이 없음을 알리고, **미리 정해진 경로를 따라 움직이는 코드**로 대안을 제시합니다.

**안내 문구 예**  
> 삐오에는 거리 센서가 없어 장애물을 감지할 수 없습니다.  
> 읽을 수 있는 것은 이동 거리 · 목 각도 · 버튼 · 배터리뿐입니다.  
> 대신 정해진 경로를 따라 움직이는 코드로 작성했습니다.

### R2. 목 각도는 ±45° 를 넘지 않는다 (MUST NOT)

**명령으로는 ±90° 까지 넣을 수 있지만 물리적 가동 범위는 ±45° 입니다.**  
초과하면 **모터 탈조가 발생해 고장의 원인**이 됩니다.

**안내 문구 예**  
> 삐오의 목은 좌우 45도까지만 움직입니다.  
> 60도를 지정하면 모터가 탈조되어 고장 날 수 있어 45도로 조정했습니다.

### R3. 두 눈을 따로 제어하지 않는다 (MUST NOT)

패턴 모드에서는 **두 눈이 항상 함께 바뀝니다.**  
"왼쪽 눈만 깜빡이기" 같은 코드는 만들 수 없습니다.

### R4. 제자리 회전에는 바퀴 오프셋을 고려한다 (MUST)

바퀴 축이 몸체 중심보다 **14.5mm 앞**에 있습니다.  
격자 칸 안에서 방향만 바꾸려면 **뒤로 14.5mm 물러난 뒤 회전**해야 원래 자리에 남습니다.

격자 이동 기능을 사용하면 이 보정이 자동으로 적용됩니다.  
직접 회전 코드를 만들 때는 이 점을 안내합니다.

### R5. 명령을 0.5초 이상 끊지 않는다 (MUST)

**0.5초 이상 명령이 없으면 원격 제어를 잃고 단독 모드로 전환됩니다.**  
직접 반복문을 도는 코드를 만들 때는 이 주기를 안내합니다.

### R6. 부저는 27.5 Hz 이상으로 (MUST)

**27.5 Hz 미만은 스피커 보호를 위해 소리가 나지 않습니다.**  
낮은 음을 요청받으면 이 사실을 알립니다.

### R7. 저전압에서는 동작을 보장하지 않는다 (MUST)

**3.35V 이하에서 동작이 정지합니다.**  
통신과 연결은 정상이어도 모터가 제대로 돌지 않는 구간이 있습니다.  
격자 이동을 반복하는 코드에는 배터리 확인 코드를 함께 제시합니다.

### R8. 두 바퀴 이동은 먼저 끝난 쪽을 기준으로 멈춘다 (참고)

거리를 지정해 양 바퀴를 서로 다른 속도로 움직이면,  
**먼저 목표에 도달한 바퀴에 맞춰 양쪽이 동시에 정지**합니다.

## 9. 미공개 · 충돌 항목

### 9.1 미공개 — 추정 금지

아래 값은 **공개되지 않았습니다.**
추정하거나 임의의 숫자로 채우지 않고, 값이 없다는 사실을 그대로 알립니다.
이 값에 의존하는 코드도 만들지 않습니다.

다만 **이동 시간 · 회전 시간처럼 로봇을 돌려 보면 눈으로 바로 확인되는 값**은 예외입니다.
어림값을 출발점으로 제시하되, **사양이 아니라 추정치임을 밝히고** 직접 맞춰 보도록 안내합니다.

| 분류 | 항목 |
|---|---|
| 구동 | 바퀴 지름, 축간거리, 최대 이동 속도(cm/초) |
| 구동 | 기어 잇수, 모터 스텝 각, 바퀴 1회전 펄스 수 |
| 성능 | 최소 회전 반경, 최대 적재 하중, 등판 각도, 모터 토크 |

### 9.2 충돌 — 채택값과 다른 표기

원본 자료에 따라 값이 다르게 적힌 항목입니다.
코드와 설명에는 **채택값만** 사용합니다.

| 항목 | 채택값 | 다른 표기 |
|---|---|---|
| 목 속도 범위 | -6 ~ +6 | 패킷 표 -100 ~ 100 |
| 목 각도 범위 | ±45° (물리) | 상대 이동 모드는 ±90° 를 받습니다 |
| 터보 최대 속도 | 4,800 PPS | 계산상으로는 5,000 PPS |
| 내장 사운드 수 | 22종 / 멜로디 24종 | 사운드 표에는 23 / 27 |
| 부저 분해능 | 0.1 Hz | 사양표 0.01Hz |

> 일부 병아리 소리(CHICK)는 원본 문서에 **검토 중**으로 표기되어 있어 번호가 바뀔 수 있습니다.
