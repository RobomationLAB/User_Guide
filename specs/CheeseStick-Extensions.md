# 치즈스틱 확장모듈 하드웨어 사양

치즈스틱에 연결하는 확장모듈의 종류와 **포트 호환 관계**를 다룹니다.

확장모듈은 아무 포트에나 꽂을 수 있는 것이 아닙니다.  
모듈마다 붙을 수 있는 포트가 정해져 있고, 서로 같은 핀을 차지해 **함께 사용할 수 없는 조합**이 있습니다.  
코드를 만들기 전에 반드시 2장의 매트릭스를 확인합니다.

본체와 포트 자체의 사양은 [치즈스틱 하드웨어 사양](CheeseStick.md)을 참조합니다.

<br>

| 항목 | 내용 |
|---|---|
| 대상 | 치즈스틱 확장모듈 (CSD · PID · HAT · NeoPixel) |
| 출시된 모듈 | **11종** |
| 미출시 모듈 | 28종 (5장 참조) |

## 1. 출시된 확장모듈

**이 11종만 코드 생성 대상입니다.**  
모듈 이름을 누르면 실물 사진과 함수 사용법이 있는 사용 가이드로 이동합니다.

| ID | 모듈 | 이름 | 종류 | 포트 |
|---|---|---|---|---|
| `CHEESESTICK.EXT.CSD01` | CSD01 | [스위치](../docs/pages/ko/CheeseStick/CSD01.md) | 입력 | S |
| `CHEESESTICK.EXT.CSD02` | CSD02 | [RGB LED](../docs/pages/ko/CheeseStick/CSD02.md) | 출력 | **L (3핀 전부)** |
| `CHEESESTICK.EXT.CSD03` | CSD03 | [로터리 퍼텐쇼미터](../docs/pages/ko/CheeseStick/CSD03.md) | 입력 | S |
| `CHEESESTICK.EXT.CSD07` | CSD07 | [소리 센서](../docs/pages/ko/CheeseStick/CSD07.md) | 입력 | S |
| `CHEESESTICK.EXT.CSD09` | CSD09 | [서보 모터](../docs/pages/ko/CheeseStick/CSD09.md) | 출력 | S (서보) · M (DC · 스텝) |
| `CHEESESTICK.EXT.CSD10` | CSD10 | [조도 센서 (ALS)](../docs/pages/ko/CheeseStick/CSD10.md) | 입력 | S |
| `CHEESESTICK.EXT.NEOPIXEL` | NeoPixel | [네오픽셀](../docs/pages/ko/CheeseStick/NeoPixel.md) | 출력 | **Sa 고정** |
| `CHEESESTICK.EXT.PID13` | PID13 | [조이스틱 & 버튼](../docs/pages/ko/CheeseStick/PID13.md) | 입력 | **L** |
| `CHEESESTICK.EXT.PID26` | PID26 | [환경 센서 (온·습도·기압)](../docs/pages/ko/CheeseStick/PID26.md) | 입력 | **L** |
| `CHEESESTICK.EXT.HAT010` | HAT010 | [5×5 RGB LED 매트릭스](../docs/pages/ko/CheeseStick/HAT010.md) | 입출력 | **HAT** |
| `CHEESESTICK.EXT.HAT022` | HAT022 | [미니 피아노 건반](../docs/pages/ko/CheeseStick/HAT022.md) | 입력 | **HAT** |

> **PID10 (초음파 거리 센서)** 은 제어 기능이 만들어져 있으나 **아직 정식 출시되지 않았습니다.**  
> 거리 측정 코드를 생성하지 않습니다. (6장 R5)

## 2. 포트 호환 매트릭스

### 2.1 모듈별 점유 핀

| 모듈 | Sa | Sb | Sc | La | Lb | Lc | Mab | Mcd | HAT |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| CSD01 스위치 | ○ | ○ | ○ | | | | | | |
| CSD02 RGB LED | | | | ● | ● | ● | | | |
| CSD03 로터리 퍼텐쇼미터 | ○ | ○ | ○ | | | | | | |
| CSD07 소리 센서 | ○ | ○ | ○ | | | | | | |
| CSD09 서보 모터 | ○ | ○ | ○ | | | | | | |
| CSD09 DC 모터 | | | | | | | ○ | ○ | |
| CSD09 스텝 모터 | | | | | | | ● | ● | |
| CSD10 조도 센서 | ○ | ○ | ○ | | | | | | |
| NeoPixel | ● | | | | | | | | |
| PID13 조이스틱 & 버튼 | | | | ● | ● | ● | | | |
| PID26 환경 센서 | | | | ● | ● | | | | |
| HAT010 LED 매트릭스 | | | | | | | | | ● |
| HAT022 피아노 건반 | | | | | | | | | ● |

**○** = 이 중 한 핀을 골라 사용 · **●** = 해당 핀을 반드시 차지함

### 2.2 함께 사용할 수 없는 조합

| 규칙 | 내용 |
|---|---|
| **L 포트는 한 모듈만** | CSD02 · PID13 · PID26 중 **동시에 하나만** 연결됩니다. 모두 L 포트를 차지합니다 |
| **NeoPixel 은 Sa 를 독점** | NeoPixel 을 사용하면 Sa 에 다른 모듈을 붙일 수 없습니다. Sb · Sc 는 그대로 사용합니다 |
| **S 포트 모듈은 최대 3개** | Sa · Sb · Sc 세 핀을 나눠 사용하므로, S 포트 모듈은 합쳐서 3개를 넘을 수 없습니다 |
| **HAT 는 한 장만** | HAT010 과 HAT022 를 동시에 꽂을 수 없습니다 |
| **스텝 모터는 M 포트 전체** | 스텝 모터를 사용하면 DC 모터를 함께 사용할 수 없습니다 |

### 2.3 자주 사용하는 조합 예

| 구성 | 가능 여부 |
|---|---|
| 스위치 + 조도 센서 + 로터리 퍼텐쇼미터 | **가능** (S 포트 3핀을 각각 사용) |
| NeoPixel + 스위치 + 조도 센서 | **가능** (NeoPixel = Sa, 나머지 = Sb · Sc) |
| NeoPixel + S 포트 모듈 3개 | **불가능** (Sa 를 NeoPixel 이 차지해 2개까지) |
| RGB LED(CSD02) + 조이스틱 & 버튼(PID13) | **불가능** (둘 다 L 포트 전체 사용) |
| RGB LED(CSD02) + 환경 센서(PID26) | **불가능** (둘 다 L 포트 사용) |
| NeoPixel + 환경 센서 + LED 매트릭스 | **가능** (Sa · L 포트 · HAT 로 각각 다름) |
| 서보 3개 + DC 모터 2개 | **가능** (서보 = S 포트 3핀, DC = M 포트 2채널) |

## 3. 모듈별 사양

### 3.1 입력 모듈

| ID | 모듈 | 측정 범위 | 비고 |
|---|---|---|---|
| `CHEESESTICK.EXT.CSD01.VALUE` | CSD01 스위치 | 눌림 / 떨어짐 | 내부 풀업 사용. **누르면 0** |
| `CHEESESTICK.EXT.CSD03.VALUE` | CSD03 로터리 퍼텐쇼미터 | 0 ~ 255 | 아날로그 입력. 범위 재지정 가능 |
| `CHEESESTICK.EXT.CSD07.VALUE` | CSD07 소리 센서 | 0 ~ 255 | 소리 크기. 절대 음압(dB) 아님 |
| `CHEESESTICK.EXT.CSD10.VALUE` | CSD10 조도 센서 | 0 ~ 255 | 밝기. 절대 조도(Lux) 아님 |

> **CSD07 과 CSD10 은 단위가 없는 상대값입니다.** "몇 dB", "몇 Lux" 로 판단하는 코드를 만들지 않습니다.

**PID13 조이스틱 & 버튼**

| ID | 항목 | 범위 |
|---|---|---|
| `CHEESESTICK.EXT.PID13.AXIS` | X · Y 축 | -128 ~ 127 |
| `CHEESESTICK.EXT.PID13.BUTTON` | 버튼 | A · B 2개 |

**PID26 환경 센서**

| ID | 항목 | 측정 범위 | 정확도 | 비고 |
|---|---|---|---|---|
| `CHEESESTICK.EXT.PID26.TEMP` | 온도 | -40 ~ +85 °C | ±1.0 °C | |
| `CHEESESTICK.EXT.PID26.HUMI` | 습도 | 10 ~ 90 %RH | ±3 %RH | **0 ~ 65°C 에서만 유효** |
| `CHEESESTICK.EXT.PID26.PRESS` | 기압 | 300 ~ 1100 hPa | ±0.6 hPa | **0 ~ 65°C 에서만 유효** |

> 초기화에 **2초 이상** 걸립니다. 연결 직후 바로 읽으면 값이 나오지 않습니다.

**HAT022 미니 피아노 건반**

| ID | 항목 | 내용 |
|---|---|---|
| `CHEESESTICK.EXT.HAT022.KEYS` | 건반 | 12키 (C · C# · D · D# · E · F · F# · G · G# · A · A# · B) |
| `CHEESESTICK.EXT.HAT022.BUTTONS` | 버튼 | Left · Right · Fn 3개 |

정전식 터치라 **직접 닿지 않고 가까이 가기만 해도** 반응합니다.

### 3.2 출력 모듈

**CSD02 RGB LED**

| ID | 항목 | 범위 | 비고 |
|---|---|---|---|
| `CHEESESTICK.EXT.CSD02.COLOR` | 색상 | R · G · B 각 0 ~ 255 | L 포트 3핀을 PWM 으로 구동 |
| `CHEESESTICK.EXT.CSD02.BRIGHTNESS` | 실제 출력 상한 | PWM 30% | 전류 보호를 위해 라이브러리가 제한합니다 |

**CSD09 모터**

| ID | 종류 | 포트 | 범위 | 최대 개수 |
|---|---|---|---|---|
| `CHEESESTICK.EXT.CSD09.SERVO` | 아날로그 서보 | Sa · Sb · Sc | 0 ~ 180° | 3 (내부 전원 기준) |
| `CHEESESTICK.EXT.CSD09.DC` | DC 모터 | Mab · Mcd | -100 ~ 100 | 2 |
| `CHEESESTICK.EXT.CSD09.STEP` | 스텝 모터 | Mab + Mcd | 웨이브 / 풀스텝 | 1 |

기준 부품은 **SG-90 / SG-09** 서보입니다. 채널당 **500mA** 를 넘을 수 없습니다.

**HAT010 5×5 RGB LED 매트릭스**

| ID | 항목 | 내용 |
|---|---|---|
| `CHEESESTICK.EXT.HAT010.SIZE` | 화면 | 5 × 5 = **25개** 풀컬러 LED |
| `CHEESESTICK.EXT.HAT010.COORD` | 좌표 | x · y 각 0 ~ 4 |
| `CHEESESTICK.EXT.HAT010.BRIGHTNESS` | 밝기 | 0 ~ 100 |
| `CHEESESTICK.EXT.HAT010.BUTTON` | 버튼 | A · B 2개 |

**NeoPixel**

| ID | 항목 | 값 | 비고 |
|---|---|---|---|
| `CHEESESTICK.EXT.NEOPIXEL.PORT` | 연결 핀 | **Sa 고정** | 다른 핀으로 바꿀 수 없습니다 |
| `CHEESESTICK.EXT.NEOPIXEL.MAX` | 최대 개수 | **144** | HAT 를 통해 추가로 144개, 합계 288개 |
| `CHEESESTICK.EXT.NEOPIXEL.BRIGHTNESS` | 밝기 | 0 ~ 255 | |
| `CHEESESTICK.EXT.NEOPIXEL.MODE` | 방식 | GRB (3색) / GRBW (4색) | 부품 종류에 맞춰 설정 |

기준 부품은 **WS2812B** 계열입니다.  
144개를 모두 갱신하는 데 GRB 는 약 5.5ms, GRBW 는 약 6.8ms 가 걸립니다.

## 6. 코드 생성 규칙

### R1. 호환되지 않는 포트에 연결하지 않는다 (MUST NOT)

**판정** — 2.1 매트릭스에서 해당 모듈이 사용할 수 있는 포트를 확인합니다.

**안내 문구 예**  
> 조이스틱 & 버튼(PID13)은 L 포트 전용 모듈이라 Sa 핀에 연결할 수 없습니다.  
> L 포트에 연결하는 코드로 작성했습니다.

### R2. 함께 사용할 수 없는 조합을 만들지 않는다 (MUST NOT)

**판정** — 2.2 의 5가지 규칙을 확인합니다. 특히 **L 포트를 사용하는 모듈은 동시에 하나만** 가능합니다.

**안내 문구 예**  
> RGB LED(CSD02)와 환경 센서(PID26)는 함께 사용할 수 없습니다.  
> 둘 다 L 포트를 차지하는데 치즈스틱의 L 포트는 하나뿐입니다.  
> 빛 표현이 함께 필요하다면 **NeoPixel(Sa 핀)** 로 바꾸면 두 가지를 같이 사용할 수 있습니다.  
> 그 구성으로 아래와 같이 작성했습니다.

### R3. S 포트 모듈은 3개까지 (MUST)

Sa · Sb · Sc 세 핀뿐입니다. 4개 이상을 요청받으면 **핀이 모자란다는 사실을 알리고**,  
HAT 모듈로 대체할 수 있는지 검토해 제시합니다.

NeoPixel 을 함께 사용하면 Sa 가 차지되어 **2개까지**만 가능합니다.

### R4. 미출시 모듈 코드를 생성하지 않는다 (MUST NOT)

5장의 모듈은 **제공되지 않습니다.** 기능만 보고 코드를 만들지 않습니다.

**안내 문구 예**  
> 치즈스틱의 적외선 송수신 모듈(PID15)은 아직 출시되지 않았습니다.  
> 현재 사용할 수 있는 입력 모듈은 스위치 · 로터리 퍼텐쇼미터 · 소리 센서 · 조도 센서 ·  
> 조이스틱 & 버튼 · 환경 센서 · 피아노 건반입니다.

### R5. 초음파 거리 센서는 아직 사용할 수 없다 (MUST NOT)

**PID10 은 제어 기능이 만들어져 있지만 정식 출시되지 않았습니다.**  
"거리를 재서 멈추기" 같은 요청을 받으면 코드를 만들지 말고 미출시임을 알립니다.

물체 감지가 필요하면 **소리 센서**나 **조도 센서**로 대체할 수 있는지 검토해 제시합니다.

### R6. 상대값 센서를 절대 단위로 사용하지 않는다 (MUST NOT)

소리 센서(CSD07)와 조도 센서(CSD10)는 **0 ~ 255 의 상대값**입니다.  
dB 나 Lux 같은 절대 단위로 변환하거나 비교하는 코드를 만들지 않습니다.

기준이 필요하면 **현재 값을 먼저 읽어 기준으로 삼는 방식**으로 코드를 작성합니다.
