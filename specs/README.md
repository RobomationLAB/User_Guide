# 로보메이션 제품 하드웨어 사양

로보메이션 로봇·모듈의 **물리적 하드웨어 사양**을 정리한 문서 모음입니다.  
AI 가 로봇 제어 코드를 생성할 때, 제품이 **실제로 할 수 있는 범위 안에서만** 코드를 만들도록 하는 것이 목적입니다.

이 폴더는 문서 사이트(docs.robomationlab.com)에 공개되지 않습니다. 저장소 안에서만 참조됩니다.

<br>

## 이 문서를 사용하는 규칙

코드를 생성하기 전에 대상 제품의 문서를 확인하고, 아래를 지킵니다.

1. **문서에 적힌 범위를 벗어나는 코드를 생성하지 않습니다.**  
   벗어나는 요청을 받으면 코드를 만들지 말고, 왜 불가능한지 수치와 함께 알린 뒤  
   범위 안의 대안 코드를 제시합니다.

2. **`미공개` 로 표시된 값은 추정하지 않습니다.**  
   그 값에 의존하는 코드를 생성하지 말고, 값이 공개되지 않았음을 알립니다.

3. **충돌이 표시된 값은 표에 채택된 값을 사용합니다.**  
   채택값은 항상 더 보수적인(안전한) 쪽입니다.

4. **각 문서의 「코드 생성 규칙」 장이 다른 모든 내용보다 우선합니다.**  
   **제품마다 규칙이 다릅니다.** 한 제품의 규칙을 다른 제품에 적용하지 않습니다.

5. **함수 사용법은 이 문서의 범위가 아닙니다.**  
   함수 이름·인자·예제는 [파이썬 API 메뉴얼](https://github.com/RobomationLAB/Robomation_Python/wiki)과  
   [RobomationLAB 사용 가이드](../docs/pages/ko/roboids/)를 참조합니다.  
   이 문서는 그 함수들이 **물리적으로 어느 범위까지 유효한지**만 다룹니다.

### LED 제어 가능 여부

**LED 가 달려 있다고 해서 코드로 켤 수 있는 것은 아닙니다.**  
아래에서 "없음" 인 제품은 LED 가 펌웨어 전용이라 켜기 · 끄기 · 색 지정이 모두 되지 않습니다.

| 제품 | 코드로 제어 가능한 LED | 상태 표시 전용 LED |
|---|---|---|
| 햄스터 | 좌 · 우 LED 2개 (7색) | 통신, 충전 |
| 햄스터 S | 좌 · 우 LED 2개 (24비트 풀컬러) | 통신, 충전 |
| 터틀 | 머리 LED 1개 (24비트 풀컬러) | 통신, 충전 (꼬리) |
| 삐오 | 눈 LED 2개 + 상태 LED 1개 (24비트) | 충전 |
| **비글** | **없음** | 전원 스위치, 통신, 충전 |
| **라쿤봇** | **없음** | 손목, 전원, 통신 |
| 치즈스틱 | 확장모듈 문서 참조 (NeoPixel 등) | 전원, 통신 |

> 비글과 라쿤봇에 LED 제어 코드를 생성하지 않습니다.

> **삐오는 환경 센서가 하나도 없습니다.** 읽을 수 있는 것은 이동 거리, 목 각도, 버튼, 배터리, 신호 세기뿐입니다.

## 표기 규약

### 스펙 ID

모든 수치 항목에는 고유 ID 가 붙습니다. 형식은 `<제품>.<분류>.<항목>` 입니다.

```
RACCOON.JOINT.J1.RANGE          라쿤봇 1번 관절 회전 범위
HAMSTER_S.DRIVE.MM_PER_PULSE    햄스터 S 펄스당 이동 거리
CHEESESTICK.PORT.M.CURRENT_MAX  치즈스틱 M 포트 최대 전류
```

제품 접두어: `HAMSTER` · `HAMSTER_S` · `TURTLE` · `BEAGLE` · `PIO` · `RACCOON` · `CHEESESTICK`  
분류: `DIM`(치수) · `DRIVE`(구동) · `WORK`(동작 한계) · `JOINT`(관절) · `SENSOR` · `OUT`(제어 가능한 출력) · `INDICATOR`(제어 불가한 표시등) · `IN`(입력) · `PORT` · `POWER`

### 값의 출처 표기

| 표기 | 뜻 |
|---|---|
| (표기 없음) | 제품 기술문서에 명시된 값 |
| `계산값` | 공개된 치수로 이 문서에서 계산한 값. 실측값이 아님 |
| `라이브러리 보정값` | 기술문서에는 없고 파이썬 라이브러리 구현에 들어 있는 실측 보정 상수 |
| `미공개` | 어느 자료에도 없음. **추정 금지** |
| `미출시` `TBD` | 정식 출시되지 않음. **제어 코드 생성 금지** |
| `충돌` | 자료마다 값이 다름. 표의 값은 가장 보수적인 것을 채택했고, 다른 값은 비고에 적음 |
